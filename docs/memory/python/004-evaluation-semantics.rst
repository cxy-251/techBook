第004章：表达式求值语义
======================

核心知识点
----------

语法树与求值顺序分工不同
   运算符优先级和结合性决定表达式如何组成语法树；evaluation order 决定子表达式何时进入运行时。Python 通常从左到右求值子表达式，赋值则先完成右侧求值，再绑定左侧目标。

表达式产生对象而不是抽象数值
   名字读取、属性访问、调用、运算和下标操作都会产生对象或抛出异常。上一级语法节点继续使用这些对象，因此应追踪对象身份、协议调用和副作用，而不只看最终字面结果。

truth testing 是独立协议
   条件上下文会通过 ``__bool__`` 或 ``__len__`` 判断对象真假。``and`` 与 ``or`` 根据左操作数的 truth value 决定是否求值右侧，并返回被选中的操作数对象；``not`` 才返回布尔对象。

属性访问本身可能执行代码
   ``obj.attr`` 先求值 ``obj``，随后进入对象类型、实例状态、descriptor、``__getattribute__`` 或 ``__getattr__`` 等路径。属性读取可以产生新对象、记录状态或抛出异常。

调用分为求值、绑定和执行
   调用表达式先求值 callable 和各实参表达式，再按函数签名完成参数绑定，最后创建调用 frame 执行函数体。实参副作用可能在参数绑定错误暴露之前已经发生。

切片先构造 ``slice`` 对象
   ``obj[start:stop:step]`` 会求值目标和边界，构造 ``slice`` 对象，再把它交给 subscription 协议。切片是否复制、返回何种对象由目标类型决定。

函数创建与函数体执行有时间边界
   lambda 求值时创建 function object，函数体在调用时执行；默认参数表达式在函数对象创建时求值。赋值表达式 ``:=`` 则先求值右侧，再绑定名字，并把同一对象作为表达式结果返回。

延迟求值会延迟副作用
   短路、条件表达式、lambda body、generator expression 和 iterator 都会建立 lazy boundary。生成器创建时通常只建立迭代状态，body 与 filter 在后续推进时执行；捕获的外部状态也按实际推进时刻观察。

关键路径
--------

复杂表达式求值：

::

   按优先级和结合性建立语法树
   → 从左到右求值当前节点的子表达式
   → 产生对象或异常
   → 进入 attribute、call、truth testing、subscription 等协议
   → 短路或延迟边界决定后续节点是否执行
   → 返回选中的结果对象
   → 赋值语句再把结果绑定到目标

调用表达式：

::

   求值 callable 位置
   → 求值位置参数和关键字参数表达式
   → 按签名执行参数绑定
   → 创建调用 frame
   → 执行函数体
   → 返回对象或传播异常

概念辨析
--------

* **运算符优先级与求值顺序**：优先级决定结构；求值顺序决定对象和副作用出现的时间。
* **truth value 与表达式结果**：对象可以被临时用于真假判断；``and``、``or`` 的最终结果仍可能是原操作数对象，而非 ``True`` 或 ``False``。
* **实参求值与参数绑定**：前者产生对象并可能产生副作用；后者检查这些对象如何进入形参位置。
* **切片语法与 ``slice`` 对象**：语法只描述边界；目标对象最终决定订阅行为和返回结果。
* **立即求值与延迟求值**：立即求值在当前 frame 完成动作；延迟边界只保存执行条件或状态，真实副作用发生在后续调用、迭代或分支进入时。

本章结论
--------

阅读复杂表达式时，应先用括号还原语法树，再标记从左到右的求值点、协议分发位置和 lazy boundary，最后确认哪个对象被返回或绑定；这种顺序能够准确解释副作用、短路、参数错误、属性访问和生成器状态为何出现在特定时刻。
