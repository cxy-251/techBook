第003章：对象引用语义
====================

核心知识点
----------

对象由身份、类型和值描述
   ``is`` 判断两个引用是否抵达同一对象；``==`` 按类型的相等协议比较值。相等对象可以拥有不同 identity，同一对象则可能通过多个名字和路径被访问。

赋值建立引用关系
   名字、容器位置和对象属性保存的是对象引用。``b = a`` 只让 ``b`` 指向 ``a`` 已经指向的对象，不会自动复制对象。

重绑定与原地修改属于不同层级
   重绑定改变某个名字或位置指向的对象；原地修改在保持 identity 的情况下改变可变对象状态。共享同一对象的所有路径都能观察到原地修改。

可变性必须按对象层级判断
   ``list``、``dict``、``set`` 等可在原 identity 上改变；``int``、``str``、``tuple`` 等对象自身不可变。不可变容器仍可引用可变对象，因此外层不可变不代表整个对象图不可变。

参数传递是形参绑定
   调用函数时，形参名字绑定到实参求值得到的对象，调用过程不会自动复制对象。函数内重绑定形参只影响当前 frame；通过形参原地修改共享对象会对调用方可见。

复制边界由对象图决定
   浅拷贝创建新的外层 compound object，但复用内部元素引用；深拷贝递归复制对象图，并用 memo 处理循环和共享关系。需要隔离哪一层状态，应在复制前明确判断。

默认参数属于 function object
   默认值表达式在函数定义执行时求值，并由 function object 长期持有。省略可变默认参数的多次调用会复用同一对象，通常应使用 ``None`` 或私有 sentinel，在调用期间创建新对象。

对象生命周期取决于可达性
   删除名字只移除一条引用边。只要对象仍可从模块、frame、容器、属性、closure、默认参数、traceback 或调试器抵达，它就继续存活。外部资源的释放不应依赖垃圾回收时机。

关键路径
--------

共享对象状态变化：

::

   表达式产生对象
   → 名字、参数、属性或容器位置保存对象引用
   → 多条路径形成 alias
   → 任一路径执行原地修改
   → 所有仍指向该对象的路径观察到相同状态

复制与生命周期：

::

   确定需要隔离的对象层级
   → 浅拷贝只复制外层或深拷贝递归复制对象图
   → 新旧对象图保留或切断共享边
   → 后续逐步删除引用边
   → 对象失去所有可达路径后才具备回收条件

概念辨析
--------

* **identity 与 equality**：identity 判断是否同一对象；equality 按类型协议判断值是否相等。
* **重绑定与原地修改**：重绑定改变引用指向；原地修改改变现有对象状态。前者通常局限于当前绑定位置，后者会跨 alias 可见。
* **参数绑定与对象复制**：函数调用只建立形参到实参对象的绑定，不隐式复制输入。
* **浅拷贝与深拷贝**：浅拷贝隔离外层容器；深拷贝尝试隔离递归对象图，但资源、缓存和自定义对象可能需要专门复制协议。
* **对象生命周期与资源生命周期**：对象由引用图和垃圾回收管理；文件、锁、连接等资源应由 ``with`` 或显式关闭确定性释放。

本章结论
--------

分析 Python 状态变化时，应先画出名字、参数、属性和容器位置组成的引用图，再区分重绑定与原地修改，确认复制切断了哪些共享边，并沿剩余可达路径解释对象为何仍然存活；默认参数、closure 和 traceback 都可能成为隐蔽的长寿命引用入口。
