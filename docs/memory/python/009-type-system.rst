第009章：类型系统
================

核心知识点
----------

对象行为由类型对象决定
   每个对象头部都指向一个类型对象。``type(x)`` 暴露这条关系；算术、长度、调用、属性访问、比较、迭代和内存管理等能力最终都由对象类型提供。

类型归属与继承是两种关系
   ``type(x)`` 回答对象由哪个类型解释；``C.__mro__`` 回答类属性沿哪些基类查找。``int`` 继承 ``object``，同时 ``type(int) is type``；把这两种关系混为一谈会误判元类和属性分发。

``object`` 与 ``type`` 构成自举核心
   普通实例的类型是其类，普通类对象的类型通常是 ``type``。``type`` 继承 ``object``，而 ``type(type) is type``；这套闭合关系由解释器启动阶段建立。

``PyTypeObject`` 聚合布局和行为
   类型对象保存类型名、实例大小、数值/序列/映射协议表、调用与属性访问函数、类字典、基类、MRO、分配和释放入口。对象保存状态，类型对象保存解释状态所需的规则。

slot 把语言操作映射到固定入口
   ``len(x)``、``x + y``、``x()``、``iter(x)`` 等操作会先取得对象类型，再进入对应 slot 或协议表。slot 返回 Python 对象、协议值或错误状态，解释器再执行结果校验和 fallback。

动态分发发生在运行时
   同一个表达式面对不同类型会进入不同实现。二元运算还可能尝试反向运算和 ``NotImplemented`` fallback；长度、迭代等协议会检查返回值是否满足约束。

Python 方法通过 wrapper 连接到 slot
   用户定义类把 ``__len__``、``__call__`` 等 special method 保存在类字典中。CPython 为 heap type 建立 wrapper slot，使 C 层协议入口能回到 Python 方法。

隐式 special method lookup 以类型为中心
   ``len(obj)``、运算符和迭代语法通常直接从 ``type(obj)`` 的类型层协议查找，绕过实例字典以及实例自定义 ``__getattribute__``。给单个实例写入同名 special method 通常只影响显式属性访问。

鸭子类型依赖实际协议能力
   调用方关心对象能否完成所需操作，而非固定类名。这里的“能力”必须落到长度、迭代、调用、数值等具体协议入口，不是仅仅存在一个同名实例属性。

类型修改需要维护缓存一致性
   给类替换 special method 会改变后续协议调用。CPython 会使类型查找缓存、slot 状态或版本标记失效，使新的类行为进入后续分发路径。

关键路径
--------

类型级协议分发：

::

   Python 表达式或内置函数
   → 取得操作对象
   → 读取对象的类型
   → 定位 PyTypeObject 中的协议表或 slot
   → 调用内置实现或 wrapper
   → wrapper 查找并调用 Python special method
   → 校验结果并返回或设置异常

运行时修改类型行为：

::

   给类对象写入或删除 special method
   → 更新类字典
   → 使相关类型缓存与 slot 状态失效
   → 后续操作重新从类型层查找
   → 新实现参与协议分发

概念辨析
--------

* **对象类型与基类**：对象类型描述运行时归属；基类关系描述类对象之间的继承和属性查找顺序。
* **普通属性查找与 special method lookup**：普通 ``obj.attr`` 会考虑实例字典和 descriptor；隐式协议调用通常直接走类型 slot。
* **duck typing 与随意命名**：duck typing 依赖对象类型真正实现目标协议；实例上放置一个同名函数不等于实现隐式协议。
* **slot 与 Python 方法**：slot 是 CPython 的 C 级分发表入口；Python special method 是用户可定义的协议实现，二者由 wrapper 连接。
* **``type`` 与 ``object``**：``type`` 是多数类对象的类型，``object`` 是多数继承链的根；两者职责不同。
* **静态类型与 heap type**：内置类型常由解释器静态准备，用户类通常是运行时创建的 heap type；二者都以类型对象参与分发。
* **类型缓存与语义规则**：缓存只加速已经确定的查找语义；类结构变化后必须失效，不能改变可观察结果。

本章结论
--------

分析 Python 操作时，应沿“对象 → 类型对象 → slot/协议 → 具体实现 → 结果校验”追踪，并把类型归属、继承关系、普通属性查找和隐式 special method lookup 分开；类型系统的核心价值，是让统一语法在运行时依据对象类型稳定地选择行为。
