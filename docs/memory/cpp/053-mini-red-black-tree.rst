第053章：Mini Red-Black Tree
============================

核心知识点
----------

* 红黑树首先是二叉搜索树；平衡规则只是在保持 key 中序顺序的前提下限制树高。
* 节点保存 parent、left、right、color 与 key/value；header 哨兵常同时记录 root、leftmost、rightmost，并充当 ``end()``。
* 核心红黑性质：根为黑、空叶视为黑、红节点不能有红孩子、任一节点到后代空叶的黑色节点数相同。
* ``rotate_left`` 与 ``rotate_right`` 只做局部指针重连，保持中序顺序不变；旋转本身应是 ``noexcept``。
* 插入先按普通 BST 定位并接入红色新节点，再根据“父红”冲突执行变色与旋转修复，最终确保根为黑。
* 删除难点来自黑节点移除可能降低某条路径黑高；erase fixup 通过兄弟颜色、兄弟子节点颜色、变色和旋转把额外黑状态向上消解。
* ``lower_bound(key)`` 在搜索过程中保存“当前第一个不小于 key 的候选”，向左缩小候选或向右排除小值，因此为 O(log n)。
* iterator 自增/自减按中序后继/前驱移动；``begin`` 是 leftmost，``--end`` 是 rightmost。

关键路径
--------

1. 插入时从 root 按 comparator 向下查找父位置，并先完成 key/value 节点构造。
2. 将新节点作为红节点接入 BST，更新 header 的 root/leftmost/rightmost。
3. 若父节点为红：根据叔节点颜色选择“父叔变黑、祖父变红继续向上”或“先旋转成直线，再旋转祖父并交换颜色”。
4. 插入修复完成后强制 root 为黑。
5. 删除若有两个孩子，先用中序后继承担结构替换，再把真正被摘除节点归约为至多一个孩子的情况。
6. 若摘除的是黑节点，进入 erase fixup，根据 sibling 与其子节点颜色执行变色/旋转直至黑高恢复。
7. 每次结构修改后维护 parent 链与 header 端点信息。

概念辨析
--------

* **BST 顺序 vs 红黑平衡**：比较器决定 key 的左右关系；颜色和旋转只控制高度，不改变中序排序结果。
* **旋转 vs 交换 key/value**：旋转改变拓扑而保留节点对象；不能把旋转简单理解成元素值交换。
* **红节点插入 vs 黑节点删除**：插入红节点先不改变黑高；删除黑节点可能直接破坏黑高，因此删除修复更复杂。
* **header vs 普通节点**：header 是容器端点状态，不保存用户元素，不能被普通 iterator 解引用。
* **lower_bound vs find**：find 只接受等价 key；lower_bound 返回第一个不小于 key 的位置，即使该 key 不存在也有插入点意义。

本章结论
--------

红黑树实现应按“BST 顺序 → 父子链接 → header 端点 → 颜色/黑高”逐层验证。旋转是保持中序顺序的局部拓扑工具，insert/erase fixup 则用它和变色恢复全局红黑不变量，从而把查找、插入、删除维持在对数复杂度。
