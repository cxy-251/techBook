第026章：Search Algorithms
==========================

核心知识点
----------

* 查询算法把“找值、找条件、计数、布尔判断、子序列定位和区间比较”统一为 iterator range 上的只读遍历。
* ``find``、``find_if``、``find_if_not`` 返回第一个命中位置；未命中返回 ``last``，因此解引用返回 iterator 前必须先和 ``last`` 比较。
* ``count`` / ``count_if`` 必须扫描完整区间；只判断存在性时 ``any_of`` 或 ``find_if`` 能在结果确定后提前结束。
* ``all_of``、``any_of``、``none_of`` 的空区间结果分别为 true、false、true；业务若要求“至少一个元素”，必须额外检查非空。
* ``search`` 查找完整子序列，朴素路径可能同时受主区间长度和模式长度影响；``adjacent_find`` 只检查相邻元素对。
* ``mismatch`` 返回两个区间第一处差异的位置，``equal`` 只返回整体是否相等；二者都依赖两个区间的边界和比较关系。
* 单向查询通常接受 input iterator；需要重复读取同一位置关系的 ``search``、``adjacent_find`` 等通常需要 forward iterator。
* 查询 algorithm 本身不修改容器；后续根据查询结果执行 ``erase``、``insert`` 等操作时，iterator 失效规则重新由容器决定。

关键路径
--------

1. 明确查询结果需要的是位置、数量、布尔值、子区间还是差异位置。
2. 对单元素查询选择 ``find`` 家族；完整值相等用 ``find``，字段或复合条件用 ``find_if``，找第一处条件失效用 ``find_if_not``。
3. 需要数量时使用 ``count`` 家族；只要存在性时使用 ``any_of`` / ``find_if``，避免无意义的完整扫描。
4. 模式是一个区间时使用 ``search``；只判断相邻关系时使用 ``adjacent_find``。
5. 比较两个区间时先保证第二个区间长度边界合法，再根据需要选择 ``mismatch`` 或 ``equal``。
6. 返回 iterator 后先检查尾哨兵，再读取元素；若准备修改容器，重新检查该容器对应的失效规则。

概念辨析
--------

* **find 与 count**：``find`` 交付第一个位置并可提前结束；``count`` 交付总数量并需要完整遍历。
* **count_if > 0 与 any_of**：二者可表达存在性，``any_of`` 更直接，并允许短路。
* **find 与 search**：``find`` 的模式是单个值；``search`` 的模式本身是一段序列。
* **adjacent_find 与 search**：前者只观察相邻两个元素；更长模式应使用 ``search``。
* **mismatch 与 equal**：前者保留第一处差异的位置，后者把同一判断压缩成 bool。
* **algorithm 查询与容器查找**：树形、哈希容器的成员 ``find`` 能利用内部索引；通用 ``std::find`` 只能沿 iterator 线性扫描。

本章结论
--------

查询算法的选择先看“要什么返回形态”，再看区间与 iterator 能力。位置查询、数量查询、布尔查询、子序列查询和区间比较虽然接口不同，本质都由半开区间遍历、比较/谓词调用和尾边界判断组成。
