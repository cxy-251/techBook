第055章：抢占与定时器路径中的延迟来源
=====================================

核心知识点
----------

延迟必须按阶段拆分
   调度延迟是 task 从 runnable 到真正运行的时间；timer 延迟至少包含逻辑到期到回调入口的交付延迟，以及回调入口到退出的执行时间。

长不可抢占区阻塞 task 切换
   ``need_resched`` 已经设置时，``preempt_count``、spinlock、hardirq 或 softirq 状态仍可能阻止调度。临界区越长，更高优先级 task 的等待上界越大。

长关中断区同时阻塞事件进入
   本地 IRQ 关闭期间，设备中断、clockevent 和 timer 处理入口都会被推迟。因此关中断不仅影响调度，还会直接制造 timer 交付延迟。

临界区风险由最坏规模决定
   固定且短小的状态更新通常只是必要同步；包含大循环、日志、回调或设备访问的临界区会随输入和负载放大，形成长尾延迟。

重 timer 回调会阻塞时间路径
   回调在 atomic 上下文中运行过久，会推迟后续 timer、softirq 和调度检查。回调应保留最小到期处理，把复杂工作转移到 workqueue 或线程。

延后工作是在不同延迟之间取舍
   Workqueue 增加一次排队和调度等待，却能缩短不可睡眠路径。必须区分哪些动作必须立即完成，哪些动作可以接受线程调度延迟。

局部 CPU 压力会串联多类延迟
   IRQ storm、softirq backlog、timer storm、pinned timer 和 per-CPU 工作可能集中占用单个 CPU，使 timer 晚到、task 唤醒后排队和调度 tick 延后连续发生。

高精度时间不能消除执行阻塞
   hrtimer 可以精确表示目标时间，仍无法越过长关中断区、重回调或 CPU 拥塞。精确截止与准时交付是不同能力。

PREEMPT_RT 缩短但不会消灭原子区
   IRQ 线程化和锁语义变化能够降低部分最坏延迟，``raw_spinlock_t`` 和底层关中断路径仍然存在。分析时必须记录实际抢占模型。

可靠归因需要完整时间线
   应分别记录计划到期、IRQ 进入、timer 回调入口与退出、``sched_wakeup`` 和 ``sched_switch``。只有把 CPU 中间执行内容放入时间线，才能确定延迟发生在哪个边界。

关键路径
--------

拆解一次 timer 唤醒延迟：

::

   记录 timer 计划到期时间
   → 找到 clockevent 或 IRQ 实际进入时间
   → 计算事件交付延迟
   → 找到 timer 回调入口与退出
   → 计算回调执行时间
   → 找到回调触发的 sched_wakeup
   → 找到目标 task 作为 sched_switch next
   → 计算 wakeup-to-run 延迟
   → 分别归因事件、回调或调度阶段

定位长不可抢占或关中断区：

::

   捕获最长 preemptoff、irqsoff 或 preemptirqsoff 区间
   → 找到禁止状态的入口
   → 找到恢复点
   → 检查锁、循环、日志和设备访问
   → 判断耗时是否随负载增长
   → 缩小临界区或拆分批次
   → 在同一负载下重新比较长尾

减轻重 timer 回调：

::

   回调确认到期对象
   → 完成最小原子状态更新
   → 唤醒等待者或 queue_work
   → 立即退出 timer 路径
   → worker 完成可睡眠复杂处理
   → teardown 同步 timer、work 与宿主对象

概念辨析
--------

不可抢占与关中断
   不可抢占主要阻止 task 切换；关中断还会推迟 timer、clockevent 和设备 IRQ 进入 CPU。

Timer 精度与 timer 交付
   精度描述目标时间的表达能力；交付描述执行入口何时真正获得处理机会。

Timer 交付延迟与回调耗时
   前者是逻辑到期到回调入口；后者是回调入口到退出。

回调唤醒与 task 实际运行
   唤醒只让 task 进入 runnable 状态，task 仍可能继续在 runqueue 中等待。

延后工作与消除延迟
   延后工作缩短 atomic 路径，不会消除复杂工作的 CPU 消耗和线程调度时间。

平均延迟与最坏延迟
   平均值描述常态；P99、P99.9 和最大值揭示临界区、IRQ 与局部拥塞造成的实时风险。

本章结论
--------

抢占与定时器延迟必须拆成事件交付、回调执行和任务调度三段；长关中断区、长不可抢占区与重回调分别阻塞不同阶段。
