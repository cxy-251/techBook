第170章：在运行系统上安全调优
==============================

核心知识点
----------

Live Tuning 是受控实验
   修改参数只是中间动作，完整实验还包括症状、路径假设、基线、作用域、单变量、观察窗口、停止条件、回滚与复盘。

调优必须从可测症状开始
   “系统慢”应拆成吞吐、p50/p99、错误率、利用率、饱和、队列和资源等待，再定位到调度、内存、I/O、网络或设备路径。

假设要连接参数与中间状态
   有效假设应说明参数改变哪个队列、阈值、周期或选择逻辑，以及哪些内核统计和业务指标会随之变化。

基线必须覆盖同一负载窗口
   修改前要记录 Kernel、Boot ID、硬件、Firmware、拓扑、配置、工作负载和参数原值；累计计数器应按固定间隔计算增量。

一次只改变一个关键变量
   同时修改 sysctl、队列、线程数和应用行为会破坏因果归因。单变量实验仍需同时观察收益、错误、内存和尾延迟。

四个属性决定变更边界
   Scope 描述整机、Namespace、Cgroup、设备、队列、模块或进程；Lifetime 描述何时读取；Reversibility 描述怎样恢复；Persistence 描述重启或对象重建后由谁应用。

文件新值不等于下游状态改变
   Sysctl、Sysfs、Module Parameter 和 Debugfs 写入成功只表示入口接受请求。验证必须进入真实队列、连接、回收、设备或异步完成路径。

调大容量常把错误变成延迟
   更深 Queue、Backlog、Socket Buffer、Timeout 和 Retry 可减少短时失败，也会增加内存、排队、故障恢复时间和请求放大。

观测本身会扰动系统
   Function Graph、全量 Trace、Audit、频繁 Debug Dump 与 Printk 会改变热路径。应先用低成本统计，再在短窗口内精确过滤。

停止条件与回滚必须预先定义
   错误率、p99、PSI、Drop、OOM、Reset 或健康检查达到阈值时应立即回滚。远程主机还需准备 Console、BMC 或自动恢复。

验证要经过三层
   首先确认参数和目标对象状态，其次确认预期中间变量变化，最后确认业务指标改善且副作用可接受。任何一层不成立都不能固化结论。

安全与多租户边界不能当作性能噪声
   关闭 Mitigation、LSM、IOMMU、Audit 或限制会改变威胁模型；提高某租户性能也可能来自抢占邻居资源，而非整机优化。

只固化可重复收益
   成功配置应在相同负载下多轮复现，覆盖 Restart、Reload、Reset 和升级边界，并进入版本管理、漂移监控和回归测试。

负结果同样是工程证据
   保持默认值可能是正确结论。失败实验应记录假设、参数、时间线和无效原因，防止重复进行同一修改。

关键路径
--------

受控调优实验：

::

   定义用户可见症状
   → 建立内核路径假设
   → 采集业务与内核基线
   → 确认 Scope / Lifetime / Rollback
   → 单独修改一个参数
   → 在固定负载窗口采样
   → 验证中间状态与业务结果
   → 回滚或固化

效果验证：

::

   回读目标参数和对象身份
   → 检查目标子系统中间指标
   → 检查队列、错误和资源副作用
   → 检查 p50/p99、吞吐和业务错误
   → 与同负载基线比较
   → 多轮重复确认因果

分阶段发布：

::

   Staging 验证正确性与故障恢复
   → 单实例 Canary
   → 达到停止条件则自动回滚
   → 扩大到小批量
   → 重新确认共享资源影响
   → 全量应用并持续监控漂移

回滚闭环：

::

   写回旧值或恢复配置
   → 验证参数文本恢复
   → 检查已有对象是否需重建
   → 必要时 Reload / Reset / Restart
   → 继续观察完整窗口
   → 确认业务和内核状态回到基线

概念辨析
--------

* 利用率与饱和：资源使用率高不必然排队，使用率低也不能排除单核、锁、Quota 或单队列瓶颈。
* 参数回读与效果验证：回读只证明控制值，实际数据路径和业务结果才证明调优生效。
* 吞吐提升与成功：吞吐增加同时伴随 p99、错误、Drop、OOM 或恢复恶化，不属于成功。
* 回滚参数与回滚状态：写回旧值可能不恢复已有连接、缓存、设备队列或异步状态。
* 默认值与未优化：默认值经测量证明不是瓶颈时，保持默认就是有效工程决策。

本章结论
--------

运行系统调优必须形成可观测、单变量、可停止和可回滚的实验闭环。缺少可重复路径证据的参数变化不应进入长期配置。
