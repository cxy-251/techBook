第029章：对象注册、查找与销毁
=============================

本章必须记住
------------

#. 对象分配完成后仍只是内存；注册把它放入索引、容器或命名空间，使其它路径可以发现它。
#. 常见发现入口包括 IDR、XArray、链表、哈希表、VFS 表、文件描述符表、driver core、sysfs 和设备节点。
#. 注册前必须完成基本字段、锁、引用计数、状态、操作表、父子关系和释放回调的初始化。
#. 发布动作应尽量靠后，因为发布后用户空间、其它 CPU、回调和异步路径可能立即访问对象。
#. 一个对象可以同时拥有多个发现入口，例如 ID 索引、sysfs 表示、设备文件和全局链表。
#. 注册一部分成功后再失败，回滚必须撤销已经发布的所有入口。
#. 查找结构只负责从 key、ID 或名字定位对象，不自动保证对象在返回后仍然存活。
#. 查找路径必须在锁、RCU 或其它保护窗口内，把候选指针转换成临时引用。
#. 锁内查找模型要求查找、状态检查和增加引用使用与删除路径一致的同步规则。
#. RCU 查找模型要求读者处于 RCU 读侧，删除方先摘除指针，再把释放推迟到 grace period 之后。
#. 需要把对象带出 RCU 读侧长期使用时，通常还要在读侧内安全提升为普通引用。
#. 文件描述符、打开句柄等模型可能已经由句柄本身持有对象引用，操作路径应遵守该句柄的 get/put 契约。
#. 引用保证内存存在，状态位决定对象是否仍接受新操作；两者必须同时检查。
#. 注销的第一目标是关闭新的发现入口，使后续 lookup、open、probe 或 sysfs 访问不能再获得对象。
#. 注销不等于最终释放，因为注销前进入的调用链仍可能持有引用或正在执行回调。
#. 对象从索引移除后，旧引用仍然有效，直到持有者完成并执行 ``put``。
#. 销毁路径通常先把对象标记为 dying，随后从所有索引和用户入口移除。
#. 注销后必须取消并同步工作队列、定时器、IRQ、异步 I/O、回调和其它可能访问对象的执行者。
#. RCU 管理的对象必须等待 grace period，确保删除前已经进入的读者全部离开临界区。
#. 最终释放只能发生在新入口关闭、旧引用归零、异步执行停止和 RCU 读者退出之后。
#. sysfs、VFS、设备节点和操作表不仅是展示结构，也是可以让外部代码进入对象的执行入口。
#. 释放对象前必须先撤销函数指针、回调表和用户入口，否则调用者可能跳入已经释放的代码或数据。
#. 创建对象主要解决怎样发布；删除对象必须同时解决怎样阻止新访问、等待旧访问和回收内存。
#. 对象销毁比创建更难，因为销毁必须处理所有已经存在的并发和异步路径。

必背路径
--------

对象注册：

::

   分配对象
   → 初始化锁、引用、状态和回调
   → 准备所有内部依赖
   → 加入内部索引
   → 创建 sysfs、VFS 或设备入口
   → 发送必要通知
   → 对象进入 active 状态

安全查找：

::

   输入 ID、名字或句柄
   → 进入锁或 RCU 保护范围
   → 从索引取得候选对象
   → 检查对象没有进入 dying 状态
   → 安全增加临时引用
   → 离开查找保护范围
   → 使用对象
   → 执行 put

对象销毁：

::

   标记对象 dying
   → 拒绝新操作
   → 从 IDR、XArray、链表或哈希表移除
   → 删除 sysfs、VFS、设备节点和其它外部入口
   → 停止产生新的异步事件
   → 取消并同步 work、timer、IRQ 和 I/O
   → 等待 RCU grace period
   → 等待旧引用归零
   → 执行 release 回调
   → 释放对象内存

RCU 删除的最小模型：

::

   读者进入 rcu_read_lock
   → 读取已发布指针
   → 删除方从索引摘除指针
   → 新读者不再看到对象
   → call_rcu、kfree_rcu 或 synchronize_rcu
   → 删除前进入的读者全部离开
   → 才允许回收对象

必须区分
--------

* 分配与注册：分配创建内存；注册创建外部发现入口和并发可见性。
* 查到指针与持有引用：查找只得到地址；临时引用才保证对象在使用期间不会被释放。
* 注销与最终释放：注销关闭新发现路径；最终释放还要等待旧引用和异步执行退出。
* 索引生命周期与对象生命周期：索引保护映射关系；对象本体还需要引用计数、RCU 或其它所有权规则保护。
* 引用保护与状态检查：引用保证内存有效；状态检查保证当前操作符合对象状态机。
* RCU grace period 与引用归零：Grace period 等待旧 RCU 读者；引用归零等待所有长期持有者，两者解决不同持有方式。

一句话结论
----------

对象注册让它可被发现，安全查找把发现转换成引用，销毁则先关闭所有入口，再等待旧使用者离开，最后释放内存。
