第029章：对象注册、查找与销毁
=============================

核心知识点
----------

注册让对象进入共享世界
   分配和初始化只建立对象本身；注册把对象放入 IDR、XArray、链表、VFS、driver core、sysfs 或设备节点，使其它执行路径能够发现并进入它。

发布动作应尽量靠后
   对象一旦可见，用户空间、其它 CPU、回调和异步任务可能立即访问它。锁、引用、状态、操作表、父子关系和释放回调应在发布前准备完成。

一个对象可以拥有多个入口
   同一对象可能同时出现在内部索引、sysfs、设备文件、全局链表和通知机制中。部分注册成功后失败，必须撤销所有已经建立的发现入口。

查到指针不等于安全持有对象
   索引只负责从 ID、名字或句柄找到候选地址。调用者通常需要在锁、RCU 或子系统规定的保护窗口内检查状态并取得临时引用，才能把对象带出查找范围。

引用与状态必须同时成立
   引用保证对象内存仍然存在，active、dying、removed 等状态决定当前操作是否合法。对象可以仍存活却已经停止服务。

注销首先关闭新的发现路径
   销毁应先标记对象停止服务，再从索引、sysfs、VFS 和设备入口中移除，使新的 lookup、open 和回调不能再获得对象。

注销不等于最终释放
   注销前已经进入的调用链可能仍持有引用，work、timer、IRQ、异步 I/O 和回调也可能继续执行。必须同步停止这些执行者并等待旧持有者离开。

RCU 与引用计数解决不同持有方式
   RCU grace period 等待删除前已经进入的短期读者；引用归零等待把对象带出查找窗口的长期持有者。销毁路径可能同时需要两种等待。

回调和操作表也是执行入口
   sysfs 属性、文件操作、设备回调和通知链不仅描述对象，还允许外部代码进入对象。释放数据或代码前必须先撤销这些入口并等待在途调用结束。

关键路径
--------

对象注册：

::

   分配并初始化对象
   → 建立锁、引用、状态和操作表
   → 加入内部索引
   → 创建 sysfs、VFS 或设备入口
   → 对象进入 active 状态

安全查找：

::

   输入 ID、名字或句柄
   → 进入锁或 RCU 保护区
   → 从索引取得候选对象
   → 检查对象仍允许获取引用
   → 增加临时引用
   → 离开查找保护区
   → 使用对象
   → 执行 put

对象销毁：

::

   标记 dying 并拒绝新操作
   → 移除所有索引和用户入口
   → 停止新的异步事件
   → 取消并同步 work、timer、IRQ 和 I/O
   → 等待 RCU 读者和旧引用
   → release 回调
   → 释放对象内存

概念辨析
--------

分配与注册
   分配创建对象内存；注册创建外部发现入口和并发可见性。

查到指针与持有引用
   查找只得到候选地址；引用才保证对象在后续使用期间不会被释放。

引用保护与状态检查
   引用保证内存有效；状态检查保证当前操作符合对象状态机。

注销与最终释放
   注销阻止新的使用者；最终释放还要等待旧引用、回调和异步执行全部结束。

RCU grace period 与引用归零
   Grace period 等待短期 RCU 读者；引用归零等待长期持有者，两者不能互相替代。

本章结论
--------

对象注册负责安全发布，查找负责把发现转换成受保护的持有，销毁则先关闭所有入口，再等待所有旧使用者离开。
