第038章：跨越用户态与内核态边界复制数据
========================================

核心知识点
----------

用户指针始终是不可信输入
   系统调用参数进入内核后，指针数值已经被接收，但它指向的数据仍位于用户地址空间，并可被用户线程修改、撤销映射或构造成非法地址。

``__user`` 标记地址空间语义
   ``__user`` 用于提醒维护者和 Sparse：该指针不能按普通内核指针访问。它只提供类型检查信息，不会自动完成运行时验证和复制。

Uaccess helper 执行受控访问
   ``copy_from_user()`` 把用户数据复制到内核缓冲区，``copy_to_user()`` 把内核数据写回用户缓冲区；标量通常使用 ``get_user()`` 和 ``put_user()``。

不同 helper 的返回语义不同
   ``copy_*_user()`` 通常返回未复制的字节数，返回零才表示全部完成；``get_user()``、``put_user()`` 通常返回零或负错误码。调用者不能使用同一种判断方式处理所有接口。

用户访问可能缺页和睡眠
   普通 uaccess 可能触发用户页缺页处理，因此通常只能在允许睡眠的上下文中执行，不能随意放进硬中断、原子区或持有 spinlock 的路径。

复制成功不等于输入有效
   Uaccess 只解决字节跨越边界的问题。长度、flag、索引、版本、权限、对象状态和字段组合仍需在内核中单独验证。

内核快照收敛 TOCTOU
   对用户数据先检查、后再次读取会留下被并发修改的窗口。可靠做法是尽早复制到内核本地对象，并在同一份快照上完成验证和使用。

可变长度输入必须先验证大小
   先复制固定头部，再检查版本、元素数量、加法和乘法溢出、偏移以及总长度上限，之后才能分配并复制剩余数据。

嵌套用户指针需要再次复制
   复制一个用户结构体只会复制其中的地址数值。结构体内部的用户指针仍然属于用户地址空间，必须再次通过 uaccess 处理。

输出对象必须完整初始化
   ``copy_to_user()`` 前应清零并填写所有公开字段，避免把内核栈残留、padding 或未初始化字段泄漏到用户空间。

Compat 数据需要先转换
   32 位用户结构体的指针、``long``、时间类型和对齐可能不同，必须按 compat ABI 读取并转换，不能直接套用 native 内核结构体布局。

长期页固定不是普通复制
   DMA、零拷贝和长期 pin user pages 涉及页引用、写入方向、回收限制和释放时机，不能把它们理解为 ``copy_*_user()`` 的性能版本。

关键路径
--------

固定结构体输入：

::

   收到 __user 指针
   → 准备内核本地结构体
   → copy_from_user 复制
   → 检查未复制字节数
   → 验证 size、flags、范围和保留字段
   → 检查权限与对象状态
   → 后续只使用内核快照

可变长度输入：

::

   复制固定头部
   → 验证版本与头部长度
   → 检查数量、偏移和整数溢出
   → 限制总大小
   → 分配内核缓冲区
   → 复制剩余数据
   → 使用稳定快照
   → 失败时释放缓冲区

向用户态返回数据：

::

   创建并清零输出对象
   → 填写公开字段
   → 保持 padding 和保留字段确定
   → copy_to_user 写回
   → 检查复制结果
   → 按接口约定返回

避免 TOCTOU：

::

   不反复读取用户字段
   → 一次复制成内核快照
   → 在快照上完成验证
   → 获取目标对象引用或锁
   → 使用同一份参数执行操作
   → 再独立处理输出边界

概念辨析
--------

用户指针与内核指针
   用户指针由用户控制且可能 fault；内核指针指向受内核生命周期规则保护的对象。

``__user`` 与 uaccess
   ``__user`` 标记地址空间；uaccess helper 才真正执行受控访问和异常处理。

``access_ok()`` 与复制成功
   ``access_ok()`` 只说明地址范围可以尝试；页面状态和实际复制仍可能失败。

块复制与标量复制
   ``copy_*_user()`` 返回未复制字节数；``get_user()``、``put_user()`` 通常返回错误码。

字节复制与业务验证
   复制成功只说明数据已移动；接口语义、权限和对象状态仍需验证。

结构体复制与嵌套数据复制
   结构体中的用户指针只是地址字段，指向的数据仍需单独复制。

地址可访问与操作被授权
   用户缓冲区可读写不表示调用者有权操作目标文件、设备或内核对象。

本章结论
--------

用户数据必须通过 uaccess 转换成稳定、经过验证的内核快照；复制、语义验证、上下文约束和对象权限是彼此独立的边界责任。
