第068章：用户地址空间与内核地址空间
=====================================

核心知识点
----------

地址值必须结合地址空间解释
   十六进制地址只是一串数值。只有确定它属于哪个进程、哪套页表、哪种映射区域和哪个权限级，才能判断它指向什么以及是否允许访问。

用户地址空间属于具体 ``mm_struct``
   程序文本、数据、堆、线程栈、共享库和 ``mmap`` 区域由进程的 VMA 集合组织。不同进程可以在相同虚拟地址放置完全不同的内容。

用户布局由多个独立范围组成
   每个 VMA 具有自己的读、写、执行、共享和后端属性。地址空间不是一整块连续已分配内存，guard page、未映射空洞和延迟分配范围都是正常组成部分。

内核虚拟空间包含多种映射区域
   常见区域包括内核文本与数据、物理内存直接映射、``vmalloc``、模块、fixmap 和 ``ioremap``。具体布局由架构、配置、页表级数和随机化共同决定。

直接映射与 ``vmalloc`` 的连续性不同
   Direct map 按物理内存关系建立内核映射，适合快速访问普通 RAM；``vmalloc`` 只保证虚拟地址连续，背后的物理页可以分散。

MMIO 不是普通内存
   ``ioremap`` 建立设备寄存器映射，返回 ``__iomem`` 语义的地址。驱动必须使用 ``readl()``、``writel()`` 等 I/O 访问器和设备顺序规则，不能按普通 RAM 指针随意解引用。

权限边界由 CPU 与页表共同执行
   用户态只能访问带用户权限的页表项。系统调用、异常或中断进入内核权限级后，内核才能访问 supervisor 映射；KPTI、SMAP、PAN 等机制进一步缩小无意或恶意跨边界访问。

用户指针始终是不可信输入
   内核不能因为权限更高就直接解引用用户地址。用户页可能缺失、权限变化或被并发修改，必须使用 uaccess 接口复制并验证数据。

随机化改变位置而不改变语义
   ASLR 和 KASLR 降低地址可预测性，但不会替代权限检查、映射类型判断和对象生命周期管理。日志地址必须结合对应构建、符号和随机化偏移解释。

关键路径
--------

解释一个用户地址：

::

   记录 PID、地址和访问类型
   → 确认目标 mm_struct
   → 在 /proc/<pid>/maps 或 VMA 集合中定位范围
   → 检查 r/w/x、文件与匿名属性
   → 检查页表 present、权限和后端状态
   → 判断正常访问、可修复缺页、权限错误或映射缺失

解释一个内核地址：

::

   确认架构、内核版本与随机化状态
   → 判断属于 kernel text、direct map、vmalloc、module 或 ioremap
   → 找到创建映射或分配对象的入口
   → 检查页表属性与符号
   → 检查对象是否仍在生命周期内

用户数据进入内核：

::

   用户提交 __user 指针
   → 系统调用进入内核
   → uaccess 检查并尝试访问
   → copy_from_user 建立内核快照
   → 验证长度、权限与业务语义
   → 内核只使用已验证快照
   → copy_to_user 返回结果

设备寄存器映射：

::

   驱动取得设备物理资源
   → ioremap 建立 MMIO 虚拟映射
   → 保存 __iomem 指针
   → 使用 I/O accessor 访问寄存器
   → remove 前停止设备与并发访问
   → iounmap 撤销映射

概念辨析
--------

用户地址与内核地址
   用户地址由具体进程的 mm 和权限解释；内核地址由架构内核虚拟布局解释。

直接映射与 ``vmalloc``
   直接映射保留与物理 RAM 的规则关系；``vmalloc`` 只保证虚拟连续。

普通 RAM 与 MMIO
   RAM 遵循普通缓存一致性和内存访问规则；MMIO 代表设备寄存器，需要专用访问器与顺序协议。

映射存在与访问允许
   页表中存在映射不代表当前权限级可以访问，CPU 仍会检查 user、write 和 execute 权限。

ASLR 与对象有效性
   随机化只改变地址位置；对象是否存在、映射是否撤销和指针是否悬空仍由生命周期决定。

地址区域与精确对象
   地址范围只能给出候选映射类型；精确对象还要结合分配来源、符号、页表和当前状态确认。

本章结论
--------

用户空间与内核空间不是按地址高低简单区分，而是由页表、权限级和映射类型共同建立的访问边界。任何地址分析都必须同时确认所属空间、映射来源、访问权限和对象生命周期。
