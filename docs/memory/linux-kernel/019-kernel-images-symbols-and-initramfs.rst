第019章：Linux 内核镜像、符号与 initramfs
=========================================

核心知识点
----------

一次构建产生多类内核产物
   内核构建不会只得到一个文件。链接产物、启动镜像、符号文件、模块和 initramfs 分别承担调试、启动、地址解析、功能扩展和早期用户空间职责。

``vmlinux`` 是链接后的内核 ELF
   ``vmlinux`` 由内建对象最终链接生成，包含段布局、符号以及可选调试信息。它适合 ``readelf``、``nm``、``objdump``、``gdb`` 和崩溃分析，不一定是 bootloader 直接加载的文件。

启动镜像由架构规则生成
   ``bzImage``、``Image``、``zImage`` 等文件遵循不同架构的启动协议。x86 常使用 ``bzImage``，arm64 常使用 ``Image``；格式、入口和加载要求不能跨架构套用。

链接脚本决定内核内存布局
   ``.text``、``.rodata``、``.data``、``.bss``、初始化段和 per-CPU 段等区域的排列由链接脚本控制。段布局既影响启动和释放时机，也影响符号与调试分析。

符号文件把地址还原成代码对象
   ``System.map`` 是构建时地址到符号的映射；``kallsyms`` 是运行内核内部的符号设施。Oops、panic 和调用栈解析需要匹配的符号信息。

地址解析必须匹配实际构建
   ``vmlinux``、``System.map``、模块调试文件和运行内核必须来自同一构建。KASLR、模块重定位和地址隐藏会改变运行地址，不能使用相似版本的符号文件替代。

initramfs 提供早期用户空间
   initramfs 通常是压缩 cpio 归档，由 bootloader 加载或嵌入内核。内核把它解包到内存 rootfs，并执行其中的 ``/init``，为最终根文件系统准备必要条件。

早期用户空间负责建立根设备路径
   ``/init`` 可以加载模块、等待设备、解锁加密卷、组装 RAID/LVM、加载固件并挂载真正根文件系统，最后通过 ``switch_root`` 等机制进入正式用户空间。

根文件系统依赖决定驱动位置
   挂载根文件系统前必需的驱动若以内建方式存在，可直接参与早期启动；若构建为模块，就必须被正确放入 initramfs，并匹配当前内核 release 和依赖关系。

可启动内核是完整交付集合
   实际启动依赖架构镜像、模块目录、initramfs、固件、启动参数和 bootloader 条目。只生成或复制一个新镜像，不代表系统已经使用该内核启动。

关键路径
--------

从源码到启动镜像：

::

   内建对象
   → 各目录 built-in.a
   → 链接脚本组织段布局
   → 生成 vmlinux ELF
   → 架构启动规则提取、压缩或包装
   → 生成 bzImage、Image 或其它启动格式
   → bootloader 按启动协议加载

initramfs 启动：

::

   bootloader 加载内核镜像与 initramfs
   → 内核解包到 rootfs
   → 执行 /init
   → 加载必要模块并准备根设备
   → 挂载最终根文件系统
   → switch_root
   → 启动正式用户空间

符号解析：

::

   日志得到地址或 function+offset
   → 确认运行内核构建身份
   → 取得匹配的 vmlinux、System.map 和模块符号
   → 处理 KASLR 与模块重定位
   → 解析为函数和源码位置
   → 回到调用链与对象状态

概念辨析
--------

``vmlinux`` 与启动镜像
   ``vmlinux`` 是链接后的 ELF；启动镜像是经过架构规则处理、符合启动协议的文件。

``vmlinux`` 与 ``vmlinuz``
   ``vmlinux`` 通常指未压缩链接产物；``vmlinuz`` 通常是发行版对可启动压缩镜像的命名。

``System.map`` 与 ``kallsyms``
   ``System.map`` 是离线构建产物；``kallsyms`` 是运行内核提供的符号解析设施。

initramfs 与最终根文件系统
   initramfs 是启动早期的临时用户空间；最终根文件系统承载系统长期运行环境。

镜像安装与实际启动
   镜像安装只更新磁盘文件；系统是否真正运行新内核，还取决于 bootloader 条目、initramfs、模块和启动后的构建身份。

本章结论
--------

``vmlinux`` 描述链接后的内核，架构镜像负责被启动，符号文件负责解释地址，initramfs 负责在最终根文件系统可用前建立早期运行环境。
