第069章：VMA、mmap 与地址空间布局
================================

核心知识点
----------

VMA 是范围级内存策略对象
   ``struct vm_area_struct`` 使用 ``[vm_start, vm_end)`` 描述一段连续虚拟地址范围，并规定该范围的权限、共享方式、后端来源和缺页处理规则。

VMA 字段连接范围、权限与后端
   ``vm_flags`` 表达读写执行、共享、增长和锁定等属性；``vm_file`` 与 ``vm_pgoff`` 连接文件映射；``vm_ops`` 允许文件系统、驱动或特殊映射提供 fault、open 和 close 等行为。

VMA 先于物理页存在
   ``mmap`` 的核心结果是建立虚拟范围和访问语义。成功返回时，许多页面仍未分配、未读入或未建立 PTE，后续首次访问再通过缺页路径补全映射。

匿名映射与文件映射具有不同后端
   匿名映射通常由零页、匿名页和 swap 承载；文件映射通过文件偏移和 page cache 获得内容。两者在缺页、回收、反向映射和回写路径中承担不同语义。

Private 与 shared 决定写入传播方式
   ``MAP_PRIVATE`` 的写入通常通过 COW 生成当前进程私有匿名页；``MAP_SHARED`` 的修改可被其它映射者观察，并可能进入文件回写或共享内存协议。

VMA 会合并与拆分
   属性兼容的相邻区域可以合并。``mprotect``、``munmap`` 和局部映射修改可能把一个 VMA 拆成多个片段，之后条件恢复一致时又可重新合并。

VMA 集合需要结构化索引与同步
   现代内核通常使用 Maple Tree 组织同一 mm 中的不重叠范围。结构性修改需要 ``mmap_lock`` 写侧保护，查找、缺页和遍历则使用相应读侧或专门协议。

Fault 路径先解释范围，再处理页面
   CPU 访问失败后，内核先查找覆盖地址的 VMA，再检查访问类型和 ``vm_flags``，最后进入匿名分配、文件页装入、COW 或 ``vm_ops->fault``。

VMA 指针本身也有生命周期
   释放 ``mmap_lock`` 后，VMA 可能被并发拆分、合并或删除。驱动建立用户映射时，还必须同步 VMA、设备对象、页面 pin 和 remove 路径。

关键路径
--------

创建文件映射：

::

   用户调用 mmap(fd, offset, length, prot, flags)
   → 验证长度、文件能力与权限
   → 在地址空间中选择空洞
   → 计算 vm_flags 与页表保护
   → 创建或合并 VMA
   → 记录 vm_file、vm_pgoff 与 vm_ops
   → 返回虚拟地址
   → 首次访问时 fault 装入文件页并建立 PTE

创建匿名私有映射：

::

   mmap(MAP_PRIVATE | MAP_ANONYMOUS)
   → 建立匿名 VMA
   → 初始可以没有物理页
   → 读取时使用零页或建立只读映射
   → 首次写入分配匿名页
   → 建立可写 PTE
   → 页面进入匿名反向映射与回收体系

修改局部权限：

::

   mprotect 指定 VMA 中间子范围
   → 在 mmap_lock 写侧定位原 VMA
   → 必要时拆出左侧与右侧范围
   → 修改中间 VMA 的权限
   → 更新对应页表项
   → 执行 TLB invalidation
   → 尝试合并属性重新一致的相邻 VMA

解除局部映射：

::

   munmap 指定地址范围
   → 查找所有重叠 VMA
   → 拆分边界范围
   → 从 VMA 索引中删除目标区间
   → 清除页表项并刷新 TLB
   → 归还页面、文件和 VMA 资源

概念辨析
--------

VMA 与物理页
   VMA 定义地址范围的含义；物理页保存某个虚拟页当前实际数据。

``mmap`` 成功与页面驻留
   成功表示范围策略已经建立，不表示页面已全部分配、读入或驻留。

``MAP_PRIVATE`` 与 ``MAP_SHARED``
   Private 写入通常形成 COW 私有页；shared 修改可传播给其它映射者并可能回写后端。

文件映射与匿名映射
   文件映射依赖文件偏移和 page cache；匿名映射依赖匿名页、零页和 swap。

用户调用次数与 VMA 数量
   VMA 会自动合并和拆分，因此当前对象数量不能由 ``mmap`` 调用次数直接推断。

VMA 权限与 PTE 权限
   VMA 保存范围策略；页表项保存当前页级硬件权限，修改时两者必须保持一致。

本章结论
--------

VMA 在页面出现之前就定义地址范围的权限、来源和 fault 策略；``mmap`` 建立的是这种范围语义，而真实页面和页表项通常在后续访问中按需形成。
