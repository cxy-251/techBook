必背课本
========

这里保存从 AIBook 完整章节中提炼出的可直接记忆知识。

定位
----

* AIBook 负责完整讲解、推导、源码、案例和实验；
* ``docs/tracks/`` 保留 techBook 原有学习内容；
* ``docs/memory/`` 只保存稳定、可信、可以直接背诵的结论。

每章固定提供“核心知识点”“关键路径”“概念辨析”和“本章结论”。这里不设置提问、练习、互动步骤或来源章节。
