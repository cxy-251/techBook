必背课本
========

这里保存从 AIBook 完整章节中提炼出的可直接记忆知识。

定位
----

* AIBook 负责完整讲解、推导、源码、案例和实验；
* ``docs/tracks/`` 保留 techBook 原有学习内容；
* ``docs/memory/`` 只保存稳定、可信、可以直接背诵的结论。

每章固定提供“本章必须记住”“必背路径”“必须区分”“一句话结论”和来源。这里不设置提问、
练习或互动步骤。

-----------------------

生产规则
--------

所有内容遵守 `必背课本内容合同 <../../project/MEMORY_CONTENT_CONTRACT.rst>`_。每本书按 AIBook 的
Part、章节号和源文件顺序建立，不重新发明另一套目录。
