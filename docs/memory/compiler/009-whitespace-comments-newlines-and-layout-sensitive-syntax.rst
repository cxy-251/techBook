第009章：Whitespace, Comments, Newlines, and Layout-Sensitive Syntax
====================================================================

核心知识点
----------

* 空格、制表符、换行和注释并不天然“无意义”；语言可以把它们当分隔符、可忽略 trivia，或直接提升为语法材料。
* 普通空白最基本的职责是阻止相邻字符合并成同一 token；是否进入 parser 取决于语言语法。
* 注释通常不形成普通 AST 节点，但其源码范围仍服务诊断、格式化、文档提取、IDE 和源码重写。
* 换行可能只是空白，也可能结束逻辑行、触发自动分号插入，或与缩进共同定义语句块。
* 布局敏感语言常由 lexer 维护缩进栈，并把视觉布局转换成 ``NEWLINE``、``INDENT``、``DEDENT`` 等显式 token。
* 括号嵌套、续行和空行会影响换行是否产生结构 token，因此 layout lexer 通常是有状态扫描器。

关键路径
--------

* 普通空白：扫描连续空白 → 更新位置 → 若不承载语法则跳过 → 从下一有效字符继续 token 化。
* 注释：识别注释起点 → 扫描到行尾/终止符 → 保留 source range 或 trivia → 主 parser 通常跳过内容。
* 逻辑换行：遇到物理换行 → 检查括号嵌套/续行/语言规则 → 产生 NEWLINE、插入分号或仅更新行号。
* 缩进：逻辑行开头计算缩进列 → 与缩进栈顶比较 → 相等不变、更大压栈并发出 INDENT、更小连续出栈并发出 DEDENT。
* parser 最终消费的是已经显式化的布局结果，而不是重新计算每行视觉缩进。

概念辨析
--------

* **物理行与逻辑行**：文件中的换行不一定结束语句；括号内续行等规则可以让多个物理行组成一个逻辑行。
* **被忽略与被丢弃**：注释可以不参与语法，却仍保存在 trivia/source map 中；“parser 不看”不等于“工具链不需要”。
* **缩进与显示宽度**：一旦缩进参与语法，tab 展开和列计算必须有确定规则，不能依赖编辑器视觉效果。
* **显式分隔符与布局 token**：花括号语言把块边界写进源码；布局语言由 lexer 把缩进变化转成等价的结构 token。

本章结论
--------

空白处理是词法结构的一部分。分析布局问题时，应先确认 token 边界，再确认换行是否结束逻辑语句，随后检查 INDENT/DEDENT 或自动分号规则，最后检查注释与源码位置是否通过旁路证据被保留。
