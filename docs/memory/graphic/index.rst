阅读方式
--------

每章依次保留“核心知识点”“关键路径”“概念辨析”和“本章结论”。阅读时先确定对象、数据结构、空间与资源阶段，再沿关键路径复盘转换、生成和运行时消费，最后用概念边界检查图形判断是否准确。
