第009章：数值方法与精度
=======================

核心知识点
----------

连续问题必须由有限表示近似
   曲线、运动、物理约束、光照和图像重建在程序中都被离散为有限样本、有限时间步和有限位宽。模型误差、离散化误差、截断误差、迭代误差与舍入误差可能同时存在，需要按进入系统的位置分别判断。

时间步长控制动态系统的稳定边界
   积分器用 ``dt`` 把连续微分方程变成状态更新。步长过大可能越过碰撞、放大弹簧能量或使 solver 不收敛；可变帧率直接驱动物理会让结果依赖负载。固定 simulation step 与独立 render interpolation 能分离稳定性和显示平滑度。

插值方法必须匹配对象空间
   标量、颜色和普通位置适合 ``lerp``；单位方向与旋转适合 ``slerp`` 或归一化插值；三角形属性由 barycentric interpolation 生成；路径和动画曲线可使用 Hermite、Catmull-Rom 或 B-Spline。参数均匀不等于空间速度均匀，恒速运动通常需要弧长表。

浮点精度取决于数值量级
   ``f32`` 提供相对精度，数值越大，相邻可表示值的间距越大。大世界中的小位移、大小量级混合的矩阵运算和小增量累计都可能丢失信息。camera-relative coordinates、floating origin、局部坐标和高精度 CPU 状态用于缩小 GPU 输入范围。

深度缓冲是投影后的有限精度表示
   near/far 比例、depth format、NDC 约定与 reversed-Z 决定深度值如何分布。near 过小、far 过大、共面几何或重复 pass 会使远处表面争用相同深度值，表现为 Z-fighting。

稳定性检查应从输入约束开始
   默认顺序是取值范围、归一化、时间步长、尺度相关 epsilon、守恒量或约束量、debug 可视化。输入已越界、方向未归一化或 ``dt`` 失控时，增加迭代次数或更换高阶算法不能从根本上修复结果。

epsilon 必须带单位和尺度
   零向量判断、接触容差、UV 比较和深度比较需要不同阈值。全局固定 ``1e-6`` 无法同时适配大世界坐标、单位向量和像素级误差；阈值应来自对象尺寸、纹理分辨率、深度映射或视觉容忍度。

动画与物理使用不同误差模型
   动画插值在预定义状态之间构造显示姿态，关注关键帧时间、旋转空间和层级传播；物理积分从当前状态预测下一状态，关注稳定区间、能量、约束和碰撞修正。渲染插值不能反向写回模拟状态。

关键路径
--------

固定步长模拟与渲染：

::

   收集当前 frameDt 并限制最大值
   → 累加到 simulation accumulator
   → accumulator 足够时按 fixedDt 推进一次或多次模拟
   → 保存 previous 与 current simulation state
   → 剩余时间计算 alpha
   → 仅为显示插值 previous/current
   → 渲染状态进入 buffer 与 shader

曲线路径的稳定求值：

::

   使用真实时间定位关键点区间
   → 计算范围受控的局部参数
   → 按 Hermite、Catmull-Rom 或其它样条求位置
   → 求切线并检查长度下限
   → 需要恒速时通过弧长表反查参数
   → 输出位置、方向和参数 debug 结果

数值异常定位：

::

   固定输入场景与复现帧
   → 检查数值范围、NaN、Infinity 与零长度
   → 检查归一化和权重总和
   → 固定 dt、迭代次数与 solver tolerance
   → 观察能量、速度、约束距离或深度分布
   → 可视化中间状态
   → 再比较积分器、精度或算法阶数

概念辨析
--------

* **精度与准确度**：精度描述有限表示能分辨多少信息；准确度描述计算结果与真实目标有多接近。更多位数不能消除错误模型或错误输入。
* **离散化误差与舍入误差**：离散化误差来自有限采样和时间步；舍入误差来自每次结果写入有限浮点表示。前者常随步长变化，后者常随量级和累计次数变化。
* **局部误差与累计误差**：局部误差属于单次更新；累计误差是它沿循环、层级或时间传播后的结果，可能表现为漂移、能量增长和姿态偏离。
* **``lerp`` 与 ``slerp``**：``lerp`` 沿直线插值，成本低但不保持单位长度和恒定角速度；``slerp`` 沿球面弧插值，更适合方向和四元数旋转。
* **固定步长与可变步长**：固定步长提高模拟可复现性和稳定判断；可变步长直接跟随帧率，成本简单但在尖峰帧中可能跨越稳定范围。
* **插值与积分**：插值在已知状态之间构造中间值；积分根据速度、力或导数推进未知未来状态。两者不能互相替代。
* **epsilon 与精确相等**：epsilon 表达尺度内“足够接近”；精确相等只适合离散标志或可证明完全一致的值，不适合大多数计算结果。
* **solver tolerance 与视觉误差**：tolerance 是停止迭代的数值条件；视觉误差是屏幕或场景中可接受的偏差。有效阈值应把两者通过世界尺度连接起来。

本章结论
--------

数值问题应按误差进入和传播的路径分析，而不是看到抖动就直接提高精度。阅读动画、模拟或 shader 代码时，先确认范围、空间、时间步和约束，再区分离散化、迭代与舍入误差；通过固定步长、尺度相关阈值、规范化状态、局部坐标和中间量可视化，才能建立可复现且可验证的稳定性结论。
