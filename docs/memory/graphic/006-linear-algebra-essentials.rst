第006章：线性代数基础
=====================

核心知识点
----------

向量必须同时标注语义与空间
   ``position``、``direction``、``normal``、``UV`` 和 ``color`` 都可由向量表示，但它们分别描述点、方向、表面朝向、纹理参数和颜色通道。任何相减、点乘或叉乘都必须先确认输入处于同一坐标空间且几何语义兼容。

矩阵描述空间之间的变换规则
   ``model``、``view``、``projection`` 和 normal matrix 分别承担模型到世界、世界到相机、相机到裁剪以及法线方向校正。矩阵值本身没有完整含义，必须结合向量左右乘约定、CPU/GPU 上传布局和目标空间解释。

齐次坐标区分点与方向
   位置点通常使用 ``w = 1``，会受到平移、旋转和缩放影响；方向向量通常使用 ``w = 0``，不接受平移。投影矩阵进一步改变 ``w``，固定管线随后执行 perspective divide 得到 NDC。

位置与法线走不同变换路径
   顶点位置使用完整模型矩阵；非均匀缩放下，法线应使用 ``transpose(inverse(mat3(model)))`` 形成的 normal matrix，并在插值或变换后重新归一化。直接用模型矩阵变换法线会破坏它与切平面的垂直关系。

矩阵分解用于诊断而非只用于编辑
   TRS 分解可恢复平移、旋转和缩放，基向量长度与点积可检查缩放和正交性，行列式接近零表示矩阵接近不可逆，行列式为负通常表示镜像或奇数次负缩放。存在 shear、负缩放或父子非均匀缩放时，普通 TRS 分解可能产生歧义。

向量内建函数有明确输入边界
   ``dot`` 用于投影、夹角和光照，输入必须同空间；``cross`` 构造三维垂直方向，结果受参数顺序和 handedness 影响；``normalize`` 保留方向并丢弃长度，零向量或极小向量可能产生 NaN 或不稳定结果。

对象级固定量应提前计算
   ``viewProjection``、对象级 MVP、normal matrix 等不随顶点变化的量适合在 CPU 或对象更新阶段预计算；随顶点、片元或骨骼权重变化的量留在对应 shader 阶段。阶段选择同时影响 ALU、寄存器和带宽成本。

数值范围决定可见精度
   大世界坐标会让小位移在 ``f32`` 中丢失，过小 near 与过大 far 会降低远处深度精度，接近奇异的矩阵会放大输入误差。camera-relative rendering、origin rebasing、合理深度范围和规范化状态用于控制误差进入画面。

关键路径
--------

顶点位置进入屏幕：

::

   vertex buffer 中的 model-space position
   → 乘 model matrix 得到 world position
   → 乘 view matrix 得到 view position
   → 乘 projection matrix 得到 clip position
   → 固定管线执行裁剪与 perspective divide
   → NDC 映射到 viewport 与 depth buffer

法线进入光照：

::

   model-space normal
   → normal matrix 校正非均匀缩放
   → 归一化为 world 或 view normal
   → 与同空间 light direction、view direction 计算 dot
   → clamp 背光结果
   → 与线性空间材质颜色组合为片元输出

数值异常排查：

::

   标注异常变量的数据来源、语义与空间
   → 分离 position path、normal path 与 depth path
   → 检查矩阵顺序、基向量、行列式和数值范围
   → 检查 normalize、inverse 等函数输入域
   → 检查大坐标、near/far 与累计更新
   → 用中间量可视化验证错误进入的位置

概念辨析
--------

* **向量类型与向量语义**：``vec3`` 只说明组件数量；点、方向、法线和颜色由变量所在空间、来源和使用方式决定。
* **点与方向**：点表示空间位置并接受平移；方向表示朝向或位移，不应被平移项改变。
* **模型矩阵与法线矩阵**：模型矩阵变换位置和切向几何；法线矩阵保持非均匀缩放后法线与切平面的垂直关系。
* **矩阵内存布局与乘法语义**：row-major 或 column-major 描述内存排列；左乘或右乘描述数学约定。两者相关但不是同一个问题。
* **``dot`` 与 ``cross``**：``dot`` 输出标量并度量同方向程度；``cross`` 输出垂直于两个三维输入的方向，参数顺序会改变符号。
* **归一化与缩放**：归一化删除长度信息，只保留方向；需要距离、速度或能量大小的量不能在使用前无条件归一化。
* **精度与数值稳定性**：精度描述有限表示能保留的信息；稳定性描述小输入误差是否被算法放大。提高位宽不能替代合理范围、矩阵条件和更新方式。

本章结论
--------

线性代数在图形管线中首先是一套数据与空间合同。阅读 shader 或排查画面时，应为每个向量标注语义和空间，沿位置、法线与深度三条路径检查矩阵、齐次坐标和函数输入域；只有在这些关系明确后，矩阵预计算、精度选择和数值修正才具有可靠边界。
