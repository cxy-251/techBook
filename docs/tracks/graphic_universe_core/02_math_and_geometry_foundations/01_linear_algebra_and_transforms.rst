6.2 4x4 齐次坐标系统的射影几何本质
------------------------------------------------------------------------

在三维欧几里得空间 $\mathbb{R}^3$ 中，旋转与缩放属于线性变换（满足 $T(\mathbf{u} + \mathbf{v}) = T(\mathbf{u}) + T(\mathbf{v})$），可以通过 $3 	imes 3$ 矩阵表示。然而平移变换（$\mathbf{v}' = \mathbf{v} + \mathbf{t}$）属于非线性仿射变换，无法用 $3 	imes 3$ 矩阵乘法直接合成。

齐次坐标（Homogeneous Coordinates）的引入将三维欧氏空间嵌入四维射影空间 $\mathbb{P}^3$，使得**平移、旋转、缩放与透视投影能够在单一 $4 	imes 4$ 矩阵乘法下完全统一**。

方向向量与位置点的代数区分
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于一个四维齐次向量 $\mathbf{P} = [x, y, z, w]^T$：

- **位置点 (Point)**：令 $w = 1$。当应用包含平移的仿射矩阵 $\mathbf{M}$ 时，平移分量与 $w=1$ 相乘并累加到结果中，实现空间位置的物理平移：
  
  .. math::
     \begin{bmatrix} 1 & 0 & 0 & t_x \ 0 & 1 & 0 & t_y \ 0 & 0 & 1 & t_z \ 0 & 0 & 0 & 1 \end{bmatrix} \begin{bmatrix} x \ y \ z \ 1 \end{bmatrix} = \begin{bmatrix} x + t_x \ y + t_y \ z + t_z \ 1 \end{bmatrix}

- **方向向量 (Direction Vector)**：令 $w = 0$。平移列与 $w=0$ 相乘归零，向量在空间变换中仅发生旋转与缩放，保持平移不变性。

透视除法 (Perspective Division)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在经过投影矩阵变换后，齐次坐标中的 $w_c$ 分量不再等于 1，而是记录了顶点在观察空间中的深度信息（通常 $w_c = -z_v$）。硬件在裁剪阶段之后自动执行**透视除法**：

.. math::

   \mathbf{P}_{	ext{ndc}} = \begin{bmatrix} x_c / w_c \ y_c / w_c \ z_c / w_c \end{bmatrix}

除以 $w_c$ 这一非线性操作，在几何上实现了“距离相机越远的物体，在屏幕上投影尺寸越小”的透视透视缩放法则。

6.3 透视投影矩阵 (Perspective Projection Matrix) 严格数学推导
------------------------------------------------------------------------

透视投影矩阵的目标是将观察空间中的平截头体（Frustum）挤压映射为齐次裁剪空间中的规范化边界体积。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                        对称透视视锥体几何参数定义                       |
   +-------------------------------------------------------------------------+
   垂直视场角: FOV_y, 宽高比: a = width / height, 近平面: n > 0, 远平面: f > 0
   近平面高度: h_n = 2 * n * tan(FOV_y / 2), 近平面宽度: w_n = a * h_n
   近平面边界: top = n * tan(FOV_y / 2), right = a * top

投影映射推导流程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. **X 与 Y 分量的线性缩放**：根据相似三角形比例，观察空间点 $(x_v, y_v, z_v)$（其中视线方向为 $-Z$ 轴，$z_v < 0$）在近平面 $z = -n$ 上的投影坐标为：
   
   .. math::
      x_p = -n \frac{x_v}{z_v} = n \frac{x_v}{-z_v}, \quad y_p = -n \frac{y_v}{z_v} = n \frac{y_v}{-z_v}

2. 将 $x_p, y_p$ 归一化至 $[-1, 1]$ 区间，并利用 $w_c = -z_v$：
   
   .. math::
      x_{	ext{ndc}} = \frac{x_p}{	ext{right}} = \frac{x_v}{-z_v \cdot a 	an(	ext{FOV}_y/2)} \implies x_c = \frac{x_v}{a 	an(	ext{FOV}_y/2)}
   
   .. math::
      y_{	ext{ndc}} = \frac{y_p}{	ext{top}} = \frac{y_v}{-z_v \cdot 	an(	ext{FOV}_y/2)} \implies y_c = \frac{y_v}{	an(	ext{FOV}_y/2)}

3. **Z 分量的非线性映射**：设 $z_c = A z_v + B$。对于现代底层 API（DirectX 12 / Vulkan / Metal，其 NDC 深度范围为 $z_{	ext{ndc}} \in [0, 1]$），边界条件为：
   - 当 $z_v = -n$ 时，$z_{	ext{ndc}} = 0 \implies \frac{-An + B}{n} = 0 \implies B = An$
   - 当 $z_v = -f$ 时，$z_{	ext{ndc}} = 1 \implies \frac{-Af + B}{f} = 1 \implies \frac{-Af + An}{f} = 1 \implies A = \frac{f}{n - f}, \; B = \frac{fn}{n - f}$

最终得到标准的现代底层 API 透视投影矩阵：

.. math::

   \mathbf{M}_{	ext{proj}} = \begin{bmatrix}
   \frac{1}{a 	an(	ext{FOV}_y/2)} & 0 & 0 & 0 \
   0 & \frac{1}{	an(	ext{FOV}_y/2)} & 0 & 0 \
   0 & 0 & \frac{f}{n - f} & \frac{fn}{n - f} \
   0 & 0 & -1 & 0
   \end{bmatrix}

6.4 深度缓冲精度危机与反转 Z (Reversed-Z) 数学模型
------------------------------------------------------------------------

在上述传统透视投影矩阵下，NDC 空间深度值 $z_{	ext{ndc}}$ 与观察空间实际物理深度 $z_{	ext{view}}$ 呈非线性反比关系：

.. math::

   z_{	ext{ndc}}(z_v) = \frac{f}{n - f} + \frac{fn}{(n - f)(-z_v)}

传统深度的精度灾难
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

IEEE 754 单精度浮点数（FP32）在 $[0, 1]$ 区间内的数值分布是极其非均匀的——其精度密度高度集中在接近 $0.0$ 的极小区间内。

在传统投影下，$z_{	ext{ndc}} = 0$ 对应近平面 $n$。由于 $1/z_v$ 曲线极其陡峭，**超过 80%~90% 的浮点精度被白白浪费在距离近平面仅几米以内的狭窄空间中**；而在距离摄像机几十米到数千米的广阔中远景区域，浮点精度被急剧压缩，导致相邻网格顶点的深度值在浮点舍入后完全相等，引发严重的**深度冲突与画面撕裂（Z-Fighting）**。

Reversed-Z 方案的数学救赎
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

现代工业级引擎（Unreal Engine 5、Frostbite、Unity HDRP）普遍采用 **Reversed-Z（反转深度缓冲）** 架构：

- 将近平面 $z_v = -n$ 映射为 $z_{	ext{ndc}} = 1.0$；
- 将远平面 $z_v = -f$ 映射为 $z_{	ext{ndc}} = 0.0$（当 $f 	o \infty$ 时，矩阵依旧良态收敛）。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                传统深度 vs Reversed-Z 浮点精度分布物理对比              |
   +-------------------------------------------------------------------------+

   [ 传统投影 (近=0, 远=1) ]
   物理距离: 近平面 (1m) ------------ 中景 (50m) ------------------ 远景 (1000m)
   FP32精度: [ 超高浮点密度 (浪费) ] | [ 浮点数极度稀疏 -> 引发 Z-Fighting! ]

   [ Reversed-Z 投影 (近=1, 远=0) ]
   物理距离: 近平面 (1m) ------------ 中景 (50m) ------------------ 远景 (1000m)
   FP32精度: [ 浮点正常分布 ] -------- [ 接近0.0拥有极高精度 -> 精度近乎完全均匀! ]

.. math::

   \mathbf{M}_{	ext{proj}}^{	ext{Reversed-Z}} = \begin{bmatrix}
   \frac{1}{a 	an(	ext{FOV}_y/2)} & 0 & 0 & 0 \
   0 & \frac{1}{	an(	ext{FOV}_y/2)} & 0 & 0 \
   0 & 0 & 0 & n \
   0 & 0 & -1 & 0
   \end{bmatrix} \quad (	ext{当远平面 } f 	o \infty)

配合 GPU 硬件的 `GREATER_EQUAL` 深度测试与 32 位浮点深度缓冲（`D32F`），Reversed-Z 彻底根治了开放大场景中的深度精度瓶颈。

6.5 旋转表示方法全景对比：欧拉角、旋转矩阵与四元数
------------------------------------------------------------------------

在处理三维空间旋转时，图形学发展出了三种核心代数表达范式：

.. list-table:: 三维空间旋转数学表示方法优劣对比
   :widths: 18 22 30 30
   :header-rows: 1
   :class: tight-table

   * - 旋转表达法
     - 存储开销
     - 核心代数特征
     - 工程缺陷与局限
   * - 欧拉角 (Euler Angles)
     - 3 个标量 (Yaw, Pitch, Roll)
     - 直观，符合人类空间感知，便于美术编辑
     - 旋转顺序强依赖、存在**万向节死锁** (Gimbal Lock)、无法平滑插值
   * - 3x3 旋转矩阵 (Rotation Matrix)
     - 9 个浮点数
     - 向量变换效率高，易于与其他仿射矩阵直接合成
     - 参数冗余、矩阵连续相乘累积浮点误差引发畸变（需 Gram-Schmidt 正交化）
   * - 单位四元数 (Quaternion)
     - 4 个标量 $\mathbf{q} = [w, x, y, z]$
     - 紧凑、复合旋转运算高效、支持**球面线性插值 (SLERP)**
     - 概念抽象，无法直接对几何向量进行矩阵式硬件乘加

四元数球面线性插值 (SLERP)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于骨骼动画与相机平滑过渡，四元数插值确保了角速度恒定：

.. math::

   	ext{SLERP}(\mathbf{q}_1, \mathbf{q}_2, t) = \frac{\sin((1-t)	heta)}{\sin	heta}\mathbf{q}_1 + \frac{\sin(t	heta)}{\sin	heta}\mathbf{q}_2, \quad \cos	heta = \mathbf{q}_1 \cdot \mathbf{q}_2
