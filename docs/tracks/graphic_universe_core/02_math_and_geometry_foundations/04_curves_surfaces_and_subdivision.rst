========================================================================
Chapter 9: 参数化曲线与曲面：Bézier、B样条、NURBS 与 Catmull-Clark 细分
========================================================================

.. note:: 前置背景与认知承接
   前一章解构了离散多边形网格的 2-流形拓扑判定与半边数据结构。然而在工业级 CAD 建模、动画影视渲染与高精度曲面建模中，离散多边形面片无法完美表达连续光滑的真实几何形态。本章将从参数化几何数学出发，系统推导 Bézier 曲线/曲面的伯恩斯坦基底与 de Casteljau 算法、B样条的 de Boor 递推求值、非均匀有理 B 样条（NURBS）的有理权重与节点向量，并深入剖析基于半边拓扑的 Catmull-Clark 细分曲面算法及其在 GPU 硬件曲面细分（Hardware Tessellation）管线中的实时实现。

9.1 连续几何与参数化表达：从代数多项式到参数样条
------------------------------------------------------------------------

在计算机图形学中，三维曲线与曲面的数学表达经历了从显式、隐式到参数化方程的演进：

.. list-table:: 三维几何数学表达范式对比
   :widths: 18 25 27 30
   :header-rows: 1
   :class: tight-table

   * - 表达范式
     - 数学定义形式
     - 几何优势
     - 工程缺陷与局限
   * - 显式方程 (Explicit)
     - $z = f(x, y)$
     - 计算求值直接
     - 无法表示闭合曲面、垂直切线处斜率发散
   * - 隐式方程 (Implicit)
     - $F(x, y, z) = 0$
     - 易于进行内外点判定与光线求交 ($F(\mathbf{r}(t))=0$)
     - 难以在曲面上均匀采样网格顶点
   * - **参数化方程 (Parametric)**
     - $\mathbf{S}(u, v) = [x(u,v), y(u,v), z(u,v)]^T$
     - **自由度极高，易于生成网格，天然支持局部形变**
     - 光线求交需进行数值非线性迭代 (牛顿法)

连续性阶数 (Continuity)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于连接的两段曲线或曲面片：
- **位置连续性 ($C^0 / G^0$)**：两段曲线在连接处端点重合（无裂缝）；
- **切线连续性 ($G^1$)**：连接处的切向量方向一致（视觉光滑无棱角）；
- **一阶导数连续性 ($C^1$)**：连接处的切向量方向与大小均严格相等；
- **曲率连续性 ($C^2 / G^2$)**：连接处的曲率中心与主曲率半径完全连续（汽车车身与光学反光曲面的工业级标准）。

9.2 Bézier 曲线与曲面：伯恩斯坦多项式与 de Casteljau 算法
------------------------------------------------------------------------

Bézier 曲线由法国工程师 Pierre Bézier 提出，通过一组控制多边形顶点（Control Points）直观定义空间平滑曲线。

伯恩斯坦基底函数与数学方程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

给定 $n+1$ 个空间控制点 $\mathbf{P}_0, \mathbf{P}_1, \dots, \mathbf{P}_n$，其 $n$ 次 Bézier 曲线方程定义为：

.. math::

   \mathbf{C}(t) = \sum_{i=0}^n B_{i,n}(t) \mathbf{P}_i, \quad t \in [0, 1]

其中 $B_{i,n}(t)$ 为 $n$ 次**伯恩斯坦基底多项式（Bernstein Basis Polynomials）**：

.. math::

   B_{i,n}(t) = \binom{n}{i} t^i (1-t)^{n-i} = \frac{n!}{i!(n-i)!} t^i (1-t)^{n-i}

三次 Bézier 曲线（Cubic Bézier，包含 4 个控制点 $\mathbf{P}_0, \mathbf{P}_1, \mathbf{P}_2, \mathbf{P}_3$）在工程中应用最广，其显式展开式为：

.. math::

   \mathbf{C}(t) = (1-t)^3 \mathbf{P}_0 + 3t(1-t)^2 \mathbf{P}_1 + 3t^2(1-t) \mathbf{P}_2 + t^3 \mathbf{P}_3, \quad t \in [0, 1]

de Casteljau 递推求值与细分算法
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

除了代数求值，de Casteljau 算法提供了一种数值极其稳定的几何线性插值求解路径：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                 de Casteljau 三次 Bézier 几何线性插值金字塔             |
   +-------------------------------------------------------------------------+

   P0 ----------(t)----------> P01 ----------(t)----------> P012 ----------(t)----------> C(t)
   P1 ----------(t)----------> P12 ----------(t)----------> P123
   P2 ----------(t)----------> P23
   P3

- **递推公式**：$\mathbf{P}_i^k(t) = (1-t)\mathbf{P}_i^{k-1}(t) + t\mathbf{P}_{i+1}^{k-1}(t)$，其中 $\mathbf{P}_i^0 = \mathbf{P}_i$。最终 $\mathbf{C}(t) = \mathbf{P}_0^n(t)$。

双三次 Bézier 曲面片 (Bicubic Bézier Patch)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通过两组一维伯恩斯坦基底的张量积（Tensor Product），可定义由 $4 	imes 4 = 16$ 个控制点控制的平滑曲面片：

.. math::

   \mathbf{S}(u, v) = \sum_{i=0}^3 \sum_{j=0}^3 B_{i,3}(u) B_{j,3}(v) \mathbf{P}_{i,j}, \quad (u, v) \in [0, 1]^2

9.3 B 样条 (B-Splines) 与非均匀有理 B 样条 (NURBS)
------------------------------------------------------------------------

Bézier 曲线存在显著局限：**缺乏局部支撑性（Local Support）**——移动任意一个控制点将导致整条曲线发生全局形变；且曲线阶数与控制点数量严格绑定（$n$ 个点对应 $n-1$ 次多项式）。

B 样条基函数与 Cox-de Boor 递推
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

B 样条（B-Splines）引入了**节点向量（Knot Vector: $U = \{u_0, u_1, \dots, u_m\}$）**，将控制点数量与多项式次数解耦：

.. math::

   \mathbf{C}(t) = \sum_{i=0}^n N_{i,p}(t) \mathbf{P}_i, \quad t \in [u_p, u_{m-p}]

其基函数由 **Cox-de Boor 递推公式** 定义：

.. math::

   N_{i,0}(t) = \begin{cases} 1, & 	ext{if } u_i \le t < u_{i+1} \ 0, & 	ext{otherwise} \end{cases}

.. math::

   N_{i,p}(t) = \frac{t - u_i}{u_{i+p} - u_i} N_{i,p-1}(t) + \frac{u_{i+p+1} - t}{u_{i+p+1} - u_{i+1}} N_{i+1,p-1}(t)

- **局部支集特性**：每个控制点 $\mathbf{P}_i$ 仅在区间 $[u_i, u_{i+p+1})$ 内对曲线产生物理影响，移动单个控制点绝不破坏其余部分的几何形态。

非均匀有理 B 样条 (NURBS)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

标准多项式曲线（Bézier 与 B-Spline）在数学上无法精确表示圆锥曲线（如圆、椭圆与双曲线）。NURBS 引入了**非均匀节点间距与齐次权重因子 $w_i$**：

.. math::

   \mathbf{C}(t) = \frac{\sum_{i=0}^n N_{i,p}(t) w_i \mathbf{P}_i}{\sum_{i=0}^n N_{i,p}(t) w_i}

NURBS 兼具自由曲面（Free-form Surface）表达能力与二次解析曲面的精确数学表达，成为工业 CAD/CAM 与工业设计的世界通用标准。

9.4 离散曲面细分算法：Catmull-Clark 细分曲面
------------------------------------------------------------------------

对于具有任意复杂拓扑（非规则四边形/三角形混排）的游戏与影视角色模型，参数曲面片难以无缝缝合。**细分曲面（Subdivision Surfaces）** 提供了从粗糙控制网格（Control Cage）生成无限平滑极限曲面的离散算法。

Catmull-Clark 细分四大加权规则
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Catmull-Clark 细分是工业影视动画（Pixar OpenSubdiv）的事实标准，单次迭代将任意多边形网格全部转化为全四边形网格：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                     Catmull-Clark 细分顶点分类与更新图                  |
   +-------------------------------------------------------------------------+

              V1                    E1                    V2
               +--------------------+---------------------+
               |                    |                     |
               |      Face Point    |      Face Point     |
               |          F1        |          F2         |
               |                    |                     |
            E4 +--------------------+ Edge Point (E) -----+ E2
               |                    |                     |
               |      Face Point    |      Face Point     |
               |          F4        |          F3         |
               |                    |                     |
               +--------------------+---------------------+
              V4                    E3                    V3

1. **生成新面点 (Face Points - $F$)**：
   每个多边形面片生成 1 个新面点，其位置为该面所有顶点的算术平均值：
   
   .. math::
      \mathbf{F} = \frac{1}{k} \sum_{j=1}^k \mathbf{V}_j

2. **生成新边点 (Edge Points - $E$)**：
   每条物理边生成 1 个新边点，其位置为该边两端顶点及相邻两面新面点的平均值：
   
   .. math::
      \mathbf{E} = \frac{\mathbf{V}_1 + \mathbf{V}_2 + \mathbf{F}_1 + \mathbf{F}_2}{4}

3. **平滑更新旧顶点 (Vertex Points - $V'$)**：
   原顶点 $\mathbf{V}$ 被更新为其相邻新面点平均值 $F$、相邻新边中点平均值 $R$ 及原位置的加权组合：
   
   .. math::
      \mathbf{V}' = \frac{F + 2R + (n - 3)\mathbf{V}}{n}
   
   其中 $n$ 为顶点的度数（Valence，相连边的数量），$F = \frac{1}{n}\sum \mathbf{F}_i$，$R = \frac{1}{n}\sum \frac{\mathbf{V} + \mathbf{V}_i}{2}$。

4. **连接构建新拓扑**：将每个新面点与其相邻的新边点相连，新边点与更新后的顶点相连，将原网格所有面均细分为四边形。

9.5 GPU 硬件曲面细分流水线 (Hardware Tessellation Pipeline)
------------------------------------------------------------------------

为了在实时渲染中避免高模带来的巨大显存占用与总线传输瓶颈，现代 GPU 硬件内置了专用的可编程硬件曲面细分流水线：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  现代 GPU 硬件曲面细分 (Tessellation) 管线拓扑          |
   +-------------------------------------------------------------------------+

   [ 顶点着色器 (VS) ] -> 处理低模控制点 (Control Points)
        |
        v
   [ 外壳着色器 (Hull Shader / TCS) ]
        |  * 评估控制点拓扑
        |  * 计算边与内部细分因子: TessFactor = f(相机距离, 屏幕误差)
        v
   [ 固定功能曲面细分器 (Tessellator Engine / TPG) ]
        |  * 硬件高并发生成密集参数化网格: (u, v) 坐标对
        v
   [ 域着色器 (Domain Shader / TES) ]
        |  * 根据 (u, v) 对 Bézier / PN-Triangles 几何方程求值
        |  * 采样高度置换贴图 (Displacement Map)，沿法线推移顶点位置
        v
   [ 几何着色器 / 片段着色器 (PS) ] -> 光栅化与像素着色

- **动态 LOD 优势**：远距离物体仅执行粗粒度细分（TessFactor = 1），近距离物体自动细分至亚像素级（TessFactor = 64），实现真正的视距几何自适应（LOD Continuous Adaptation）。
