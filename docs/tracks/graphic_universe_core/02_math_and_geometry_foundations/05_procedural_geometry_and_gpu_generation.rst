10.1 连续噪声数学与分形布朗运动 (Fractal Brownian Motion)
------------------------------------------------------------------------

程序化几何生成的核心数学基石是具备可微性与空间连续性的**相干噪声函数（Coherent Noise）**。传统的随机数生成器（白噪声）在空间上完全离散无序，无法用于驱动地形与连续自然形态。

Perlin 梯度噪声与 Simplex 噪声数学推导
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Ken Perlin 提出的经典梯度噪声，通过在三维整数晶格点上生成伪随机梯度向量，并利用插值多项式计算空间任意点的值：

1. **晶格点散列与梯度求取**：根据空间点 $\mathbf{x} = [x, y, z]^T$ 的整数部分确定所属单位立方体，通过置换表（Permutation Table）为 8 个晶格顶点获取伪随机梯度向量 $\mathbf{g}_0 \sim \mathbf{g}_7$。
2. **距离向量与点积**：计算点 $\mathbf{x}$ 到 8 个顶点的位移向量 $\mathbf{d}_i$，求取点积标量 $s_i = \mathbf{g}_i \cdot \mathbf{d}_i$。
3. **五次平滑插值曲线 (Quintic Blend)**：
   
   .. math::
      s(t) = 6t^5 - 15t^4 + 10t^3

   该多项式在 $t=0$ 与 $t=1$ 处的一阶导数与二阶导数均为零，确保了插值生成的标量场严格具备 **$C^2$ 二阶几何连续性**，彻底消除了视觉缝隙与法线不连续伪影。

**Simplex 噪声的几何革新**：
传统 Perlin 噪声将 $N$ 维空间划分为超立方体，采样点需要插值 $2^N$ 个顶点（3D 需要 8 点，4D 需要 16 点）。Simplex 噪声将空间划分为最简单形（Simplex：2D 为等边三角形，3D 为四面体），所需计算顶点仅为 $N+1$ 个（3D 仅需 4 点），计算复杂度由 $O(2^N)$ 骤降至 $O(N^2)$，并且彻底消除了立方体晶格的方向各向异性。

分形布朗运动 (Fractal Brownian Motion - FBM)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

自然界的地貌与云层呈现出鲜明的多尺度自相似性（Self-Similarity）。通过将多个不同频率与振幅的噪声层（Octaves）线性叠加，构建富含微观细节的分形场：

.. math::

   f(\mathbf{x}) = \sum_{k=0}^{O-1} g^k \cdot 	ext{noise}\left( l^k \cdot \mathbf{x} \right)

- $O$：倍频程数量（Octaves，通常取 4~8 层）；
- $l$：频度增量（Lacunarity，通常取 $l \approx 2.0$，每层频率翻倍）；
- $g$：增益系数（Gain / Persistence，通常取 $g \approx 0.5$，每层振幅减半）。

10.2 3D 标量场与 Marching Cubes 等值面提取算法
------------------------------------------------------------------------

当空间几何通过连续的 3D 标量场（或符号距离场 SDF: $f(x, y, z)$）表示时，物体表面定义为等值面（Isosurface: $f(x, y, z) = 	ext{isovalue}$）。**Marching Cubes 算法**负责将连续标量场离散化重建为高精度三角多边形网格。

算法微架构与查找表机制
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  Marching Cubes 体素拓扑与 8 位状态索引                 |
   +-------------------------------------------------------------------------+

              V4-------------------V5
              /|                  /|        体素状态索引 (8-bit Case Index):
             / |                 / |        Index = (V0 > iso ? 1 : 0)
            V7-------------------V6|              | (V1 > iso ? 2 : 0)
            |  |                 | |              | (V2 > iso ? 4 : 0)
            |  V0----------------|-V1             ...
            | /                  | /              | (V7 > iso ? 128 : 0)
            |/                   |/
            V3-------------------V2         全空间共 2^8 = 256 种配置情况！

1. **体素分类**：计算立方体 8 个顶点的场强值，与阈值 $	ext{isovalue}$ 比对，生成 8 位二进制索引（`0 ~ 255`）。
2. **拓扑查找表 (Lookup Tables)**：
   - 256 种配置在几何上可压缩为 15 种旋转/反转等价类；
   - 预计算 `triTable[256][16]`，常数级输出当前体素应生成的三角形索引列表（每个体素最多生成 5 个三角形）。
3. **边上顶点物理位置线性插值**：
   对于相交的物理边（两端点为 $\mathbf{P}_1, \mathbf{P}_2$，标量值为 $V_1, V_2$）：
   
   .. math::
      \mathbf{P}_{	ext{intersect}} = \mathbf{P}_1 + \frac{	ext{isovalue} - V_1}{V_2 - V_1} (\mathbf{P}_2 - \mathbf{P}_1)

4. **表面法线解析梯度求取**：
   表面的几何法线直接由标量场的中心差分梯度给出：
   
   .. math::
      
abla f(\mathbf{p}) = \left[ \frac{f(\mathbf{p} + \Delta x) - f(\mathbf{p} - \Delta x)}{2\Delta x}, \; \frac{f(\mathbf{p} + \Delta y) - f(\mathbf{p} - \Delta y)}{2\Delta y}, \; \frac{f(\mathbf{p} + \Delta z) - f(\mathbf{p} - \Delta z)}{2\Delta z} \right]^T
   
   .. math::
      \mathbf{N} = -	ext{normalize}(
abla f(\mathbf{p}))

10.3 GPU 并行几何流压缩：Parallel Prefix Sum (Scan)
------------------------------------------------------------------------

在 GPU Compute Shader 中实现并行 Marching Cubes 时，面临一个根本性的并发数据竞争难题：**不同的体素生成的三角形数量不同（0 ~ 5 个不等）**。GPU 上成千上万个线程无法预知自身生成的顶点应该写入全局顶点缓冲区的哪个物理偏移位置（Write Offset）。

若使用全局原子操作（`atomicAdd`），成千上万个线程并发抢占单一显存计数器将导致严重的硬件总线锁死与流水线停顿。

Blelloch 树状并行前缀和算法 (Work-Efficient Scan)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

通过两阶段并行前缀和（Prefix Sum / Scan）算法，在片上共享内存（LDS / Shared Memory）中实现无锁流压缩（Stream Compaction）：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                     Blelloch 并行前缀和算法两阶段拓扑                   |
   +-------------------------------------------------------------------------+

   输入数组 (各体素顶点数): [ 3,  0,  6,  0,  3,  3,  0,  3 ]
                                    |
   【Phase 1: Up-Sweep (归约树求和)】
   Step 1:                     [ 3,  3,  6,  6,  3,  6,  0,  3 ]
   Step 2:                     [ 3,  3,  6,  9,  3,  6,  0,  9 ]
   Step 3:                     [ 3,  3,  6,  9,  3,  6,  0, 18 ] (根节点总和: 18)
                                    |
   【Phase 2: Down-Sweep (下推分发基地址)】
   清零根节点并将值下推:
   输出前缀和 (无锁写入偏移量): [ 0,  3,  3,  9,  9, 12, 15, 15 ]
   * 线程 0 写入 [0 ~ 2], 线程 2 写入 [3 ~ 8], 线程 4 写入 [9 ~ 11]... 完美无锁并发！

10.4 端到端 GPU-Driven 程序化几何流水线编排
------------------------------------------------------------------------

现代图形引擎彻底废弃了“CPU 提取几何 $	o$ PCIe 上传 $	o$ GPU 渲染”的高延迟传统链路，构建了**全 GPU 驱动（GPU-Driven）纯计算闭环**：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  全 GPU 驱动 (GPU-Driven) 程序化几何生成闭环             |
   +-------------------------------------------------------------------------+

   [ Pass 1: Compute Shader (生成 3D 标量场) ]
        |  * 3D Grid 线程并发计算 FBM 噪声或物理流体网格
        |  * 输出 3D 密度场缓冲区 (Density Buffer)
        v
   [ Pass 2: Compute Shader (体素状态分类与计数) ]
        |  * 评估各体素 Case Index，查表获取生成顶点数
        |  * 写入 CountBuffer
        v
   [ Pass 3: Compute Shader (两级并行前缀和 Scan) ]
        |  * 片上 LDS 快速扫描，计算每个体素的全局写入偏移 OffsetBuffer
        |  * 将网格总顶点数原子写入 IndirectDrawArgsBuffer (间接绘制参数)
        v
   [ Pass 4: Compute Shader (顶点插值与几何写出) ]
        |  * 依据 OffsetBuffer 无锁并发将顶点/法线直接写入全局 VertexBuffer (VBO)
        v
   [ Pass 5: Graphics Pipeline (间接绘制调用) ]
           * 命令流发起 vkCmdDrawIndirect / ExecuteIndirect(IndirectDrawArgsBuffer)
           * 【全程零 CPU 介入，零 PCIe 传输，每帧直接在显存内自生成自渲染！】

10.5 工程性能与内存带宽控制法则
------------------------------------------------------------------------

在工业级实施全 GPU 程序化几何生成时，应遵循以下带宽控制准则：

1. **顶点数据位宽压缩 (Vertex Attribute Packing)**：
   - 顶点坐标在体素局部坐标系内使用 16 位归一化整型（`SNORM16`），相对于标准 `float3` 节约 50% 显存写入带宽；
   - 法线向量通过八面体编码（Octahedral Normal）压缩为 `SNORM16x2`。
2. **体素块层次化分页与视锥剔除 (Voxel Chunk Culling)**：
   - 仅对处于摄像机视锥体内部且包含表面（$	ext{Density}_{\min} \le 	ext{iso} \le 	ext{Density}_{\max}$）的有效体素块派发 Compute Shader，消除 90% 以上的空体素无效运算。
