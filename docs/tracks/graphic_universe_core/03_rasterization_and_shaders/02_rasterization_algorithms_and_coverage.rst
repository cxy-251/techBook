Chapter 12: 光栅化核心算法：2D 边缘方程、Top-Left 规则与 MSAA
========================================================================

.. note:: 前置背景与认知承接
   前一章解构了输入装配器（IA）的属性解包、顶点着色器 SIMT 执行、齐次视锥体多边形裁剪与背面剔除。当几何图元经过视口变换映射为二维屏幕坐标后，渲染流水线迎来了从连续“几何矢量域”跨越至离散“像素点阵域”的关键跃迁——光栅化（Rasterization）。本章将深入 GPU 光栅化硬件微架构，系统推导二维三角形边缘方程（Edge Functions）、Juan Pineda 并行扫描算法、Top-Left 像素填充无缝拼接规则、重心坐标透视校正插值数学模型，以及超采样（SSAA）与多重采样抗锯齿（MSAA）的子像素覆盖掩码（Coverage Mask）评估机理。

------------------------------------------------------------------------
12.1 光栅化的物理本质与图元边界判定
------------------------------------------------------------------------

光栅化器的核心物理任务，是判定一个由浮点坐标构成的连续几何图元（三角形），究竟覆盖了显示器物理网格中的哪些离散像素采样点，并为这些像素生成包含插值属性的**片段（Fragments）**。

层次化粗/细粒度光栅化硬件架构 (Hierarchical Rasterization)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

现代 GPU 硬件绝不会逐个像素去遍历整张屏幕，而是采用**两级层次化光栅化流水线**：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  现代 GPU 层次化两级光栅化硬件流水线                     |
   +-------------------------------------------------------------------------+

   [ 输入二维投影三角形: P0(x0, y0), P1(x1, y1), P2(x2, y2) ]
        |
        v
   [ 1. 轴对齐包围盒粗筛 (AABB Bounding Box) ]
        |  * x_min = max(0, min(x0, x1, x2)), x_max = min(Width-1, max(x0, x1, x2))
        v
   [ 2. 粗粒度光栅化器 (Coarse Rasterizer) ]
        |  * 以 8x8 或 16x16 像素的宏瓦片 (Macro-Tile / Chunk) 为粒度
        |  * 并发测试三角形与瓦片边界的相交性，剔除 80% 以上的空白瓦片
        v
   [ 3. 细粒度光栅化器 (Fine Rasterizer) ]
        |  * 在命中瓦片内部，以 2x2 像素四方块 (Pixel Quad) 为单元进行采样测试
        |  * 计算边缘方程与覆盖掩码 (Coverage Mask)
        v
   [ 4. 片段调度器 (Fragment Dispatcher) ] -> 压入计算核心启动像素着色器 (PS)

12.2 2D 边缘方程 (Edge Function) 与 Juan Pineda 并行扫描
------------------------------------------------------------------------

Juan Pineda 于 1988 年提出的**边缘方程（Edge Function）**，是现代所有 GPU 硬件实现三角形光栅化的代数数学基石。

边缘方程的数学推导与几何意义
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于由两点 $\mathbf{P}_0(x_0, y_0)$ 与 $\mathbf{P}_1(x_1, y_1)$ 构成的有向二维线段，空间任意采样点 $\mathbf{P}(x, y)$ 的边缘方程定义为二维叉乘：

.. math::

   E_{01}(x, y) = (\mathbf{P} - \mathbf{P}_0) 	imes (\mathbf{P}_1 - \mathbf{P}_0) = (x - x_0)(y_1 - y_0) - (y - y_0)(x_1 - x_0)

展开为标准线性隐式直线方程形式：

.. math::

   E_{01}(x, y) = A \cdot x + B \cdot y + C

其中矩阵常数项为：

.. math::

   A = y_1 - y_0, \quad B = -(x_1 - x_0) = x_0 - x_1, \quad C = x_0 y_1 - y_0 x_1

- **几何代数意义**：
  - 当 $E_{01}(x, y) > 0$ 时，点 $\mathbf{P}$ 位于有向线段的**左侧（半平面内）**；
  - 当 $E_{01}(x, y) < 0$ 时，点 $\mathbf{P}$ 位于有向线段的**右侧**；
  - 当 $E_{01}(x, y) = 0$ 时，点 $\mathbf{P}$ 恰好落在直线本身上。

三角形内部包含判定充要条件
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于逆时针缠绕（CCW）的三角形 $\Delta \mathbf{P}_0 \mathbf{P}_1 \mathbf{P}_2$，采样点 $\mathbf{P}(x, y)$ 位于三角形内部的充要条件是其同时位于三条边的左侧：

.. math::

   \begin{cases}
   E_{01}(x, y) \ge 0 \
   E_{12}(x, y) \ge 0 \
   E_{20}(x, y) \ge 0
   \end{cases}

硬件增量求值 (Incremental Evaluation) 优化
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在光栅化硬件电路中，无需为每个像素重复计算完整的乘法。当扫描线沿 X 轴步进 1 像素时：

.. math::

   E(x + 1, y) = A(x + 1) + By + C = E(x, y) + A

沿 Y 轴步进 1 像素时：

.. math::

   E(x, y + 1) = E(x, y) + B

硬件仅需使用极度精简的**整数加法器累加器（Adders）**即可在单个时钟周期内并发评估数百个像素的覆盖状态！

12.3 Top-Left 填充规则与相邻三角形无缝拼接
------------------------------------------------------------------------

当两个多边形共享一条公共边，且屏幕像素采样中心恰好精确落在该边上（$E(x, y) = 0$）时，若两个三角形都渲染该像素，半透明混合（Alpha Blending）将产生双重着色（Double Blending 伪影）；若两个三角形都不渲染，物体表面将出现一条刺眼的透明白色裂缝（Cracks/Seams）。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       Top-Left 填充规则几何边界定义                     |
   +-------------------------------------------------------------------------+

              Top 边: 水平且向左延伸 (y1 == y0 && x1 < x0)
               +===========================================+ (归属本三角形)
              /                                             \
             /                                               \
   Left 边: /                                                 \  Right 边:
   非水平且 /                                                   \ (不归属!)
   向上延伸/                                                     \
   (y1 > y0)\                                                     /
             \                                                   /
              \                                                 /
               +-----------------------------------------------+
                             Bottom 边 (不归属!)

Top-Left 规则的严格数学定义
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

依据 DirectX / Vulkan / Metal 现代规范，一条边被定义为“**Top 边**”或“**Left 边**”：

- **Top 边（顶边）**：严格水平且从右向左延伸（$y_1 = y_0 \land x_1 < x_0$）；
- **Left 边（左边）**：非水平且向左上方/左下方延伸，使得三角形内部位于该边右侧（在 CCW 缠绕下满足 $y_1 > y_0$）。

**像素包含判定法则**：
一个采样点被判定属于当前三角形，当且仅当：

.. math::

   E(x, y) > 0 \quad \lor \quad \left( E(x, y) = 0 \; \land \; 	ext{IsTopLeftEdge}(	ext{Edge}) \right)

数学保证：**屏幕上任意共享边上的像素采样中心，被且仅被其中一个三角形精准捕获一次**，从根本上消除了缝隙与过度混合。

12.4 重心坐标插值与透视校正插值 (Perspective-Correct Interpolation)
------------------------------------------------------------------------

当判定像素被三角形覆盖后，必须通过**重心坐标（Barycentric Coordinates）**计算该像素对应的深度、法线、切线与纹理坐标。

重心坐标的边缘方程表达
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

三角形总有向面积 $2A = E_{01}(x_2, y_2)$。点 $\mathbf{P}(x, y)$ 的三维重心坐标 $(\alpha, \beta, \gamma)$ 可直接由边缘方程归一化求得：

.. math::

   \alpha = \frac{E_{12}(x, y)}{2A}, \quad \beta = \frac{E_{20}(x, y)}{2A}, \quad \gamma = \frac{E_{01}(x, y)}{2A}, \quad 	ext{满足 } \alpha + \beta + \gamma = 1

透视投影引起的非线性插值畸变
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在经过透视投影后，观察空间中的均匀距离在屏幕空间中呈现非线性的“近密远疏”压缩。若直接在屏幕空间利用重心坐标对顶点属性 $\Phi$ 进行简单线性插值（Affine Interpolation）：

.. math::

   \Phi_{	ext{affine}}(x, y) = \alpha \Phi_0 + \beta \Phi_1 + \gamma \Phi_2 \quad (	ext{完全错误！纹理发生剧烈扭曲})

透视校正插值严格代数方程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

三维物理空间中的属性 $\Phi$ 与齐次裁剪空间深度倒数 $1/w$ 的乘积，在屏幕空间中严格保持线性。光栅化硬件执行**透视校正插值**：

.. math::

   \Phi_{	ext{correct}}(x, y) = \frac{\alpha \frac{\Phi_0}{w_0} + \beta \frac{\Phi_1}{w_1} + \gamma \frac{\Phi_2}{w_2}}{\alpha \frac{1}{w_0} + \beta \frac{1}{w_1} + \gamma \frac{1}{w_2}}

硬件插值单元（Interpolator）并发计算分子（属性除以 $w$ 的插值）与分母（深度倒数的插值），最后执行一次除法恢复出真实的物理几何属性。

12.5 抗锯齿架构演进：SSAA、MSAA 与子像素覆盖掩码
------------------------------------------------------------------------

由于屏幕物理像素是离散的方格，高频几何多边形边缘在采样时必然产生阶梯状走样（Aliasing / Jaggies）。

.. list-table:: 硬件抗锯齿技术微架构对比
   :widths: 20 25 25 30
   :header-rows: 1
   :class: tight-table

   * - 抗锯齿技术
     - 几何覆盖率采样率
     - 像素着色器执行频次
     - 显存带宽与算力开销
   * - **无抗锯齿 (1x None)**
     - 1 Sample / 像素
     - 1 次 / 像素
     - 基准开销 (存在严重锯齿)
   * - **超级采样 (SSAA 4x)**
     - 4 Samples / 像素
     - **4 次 / 像素 (400% 算力)**
     - 4x 显存与 4x 算力开销，画质完美但极其昂贵
   * - **多重采样 (MSAA 4x)**
     - 4 Samples / 像素
     - **1 次 / 像素 (100% 算力!)**
     - 仅多分配 4x Depth/Stencil 缓冲区，算力开销极低

多重采样抗锯齿 (MSAA) 硬件覆盖评估机制
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

MSAA 实现了渲染效率与边缘平滑的绝妙平衡：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                    4x MSAA 像素内子采样点覆盖评估模型                   |
   +-------------------------------------------------------------------------+

   物理像素边界:
   +---------------------------------------+
   |      (S0: 点外)                       |   三角形多边形边缘
   |          *                            |      /
   |                     (S1: 点内)        |     /
   |                         *             |    /
   |      [ 像素中心: 执行 1 次 PS 着色! ] |   /
   |                                       |  /
   |      (S2: 点内)                       | /
   |          *              (S3: 点内)    |/
   |                             *         /
   +--------------------------------------/+

1. **子像素覆盖评估 (Coverage Evaluation)**：
   光栅化器对像素内的 4 个子采样点（$S_0 \sim S_3$）分别代入边缘方程，生成 4 位**覆盖掩码（Coverage Mask）**（如 `0b1110`，表示 $S_1, S_2, S_3$ 命中三角形内部）。
2. **单一着色器调用 (Single PS Invocation)**：
   只要 Coverage Mask 不全为 0，像素着色器在像素中心**仅执行 1 次计算**，生成唯一的颜色值 $C$。
3. **分像素深度测试与颜色写入**：
   命中的 3 个子采样点分别独立执行深度测试。通过测试后，将颜色 $C$ 写入对应的子采样点颜色缓冲区。
4. **解析输出 (Resolve Pass)**：
   在渲染通道末尾，硬件将 4 个子采样点的颜色加权平均：$	ext{FinalColor} = \frac{0 \cdot C_{	ext{bg}} + 3 \cdot C}{4} = 0.75 C + 0.25 C_{	ext{bg}}$，在几何边缘呈现极致平滑的过渡半色调。

小结与下章导读
