------------------------------------------------------------------------
11.1 输入装配器 (Input Assembler) 与顶点属性解包微架构
------------------------------------------------------------------------

图形渲染流水线在硬件上的第一站是**输入装配器（Input Assembler - IA）**。IA 是一个专用的硬件固定功能单元，负责从显存中的顶点缓冲区（VBO）和索引缓冲区（IBO）拉取无格式的原始二进制字节流，并将其根据管线状态对象（PSO）中的**顶点输入布局描述符（Vertex Input Layout）**解包为结构化的顶点属性。

顶点输入布局描述符与硬件字段映射
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table:: 现代底层图形 API (DirectX 12 / Vulkan) 顶点属性布局规范
   :widths: 20 22 28 30
   :header-rows: 1
   :class: tight-table

   * - 布局字段
     - 典型参数值
     - 硬件解析行为
     - 物理对齐与性能考量
   * - `SemanticName / Location`
     - `POSITION`, `NORMAL`, `TEXCOORD0`
     - 绑定至顶点着色器的输入属性寄存器 (`v0, v1, v2`)
     - 驱动在编译期确立硬件寄存器槽位映射
   * - `Format`
     - `DXGI_FORMAT_R32G32B32_FLOAT`
     - 定义属性分量数量与数据编码类型
     - 硬件单周期自动将 `INT8/SNORM` 解包为 FP32 浮点数
   * - `InputSlot`
     - `Slot 0`, `Slot 1`
     - 绑定的物理顶点缓冲区绑定点 (Binding Slot)
     - 支持分流缓冲 (SoA) 多流并行读取
   * - `AlignedByteOffset`
     - `0, 12, 24, 32` (字节偏移)
     - 当前属性在顶点结构体内的起始相对字节位置
     - 必须严格遵循 4 字节/16 字节硬件自然对齐
   * - `InputSlotClass`
     - `PER_VERTEX` vs `PER_INSTANCE`
     - 数据步进频率 (Step Rate) 控制
     - 实例化渲染时，每绘制一个实例才步进一次偏移

硬件定点数到浮点数的解压 (Type Decompression)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

为了节约显存带宽，法线与切线通常以压缩格式存储（如 8 位有符号整型 `R8G8B8A8_SNORM`）。IA 硬件内置了专用解压电路，在拉取数据的瞬间以**零 ALU 周期开销**将定点数实时还原为标准单精度浮点数：

.. math::

   f_{	ext{FP32}} = \max\left( \frac{	ext{int8\_val}}{127.0}, \; -1.0 \right)

11.2 顶点着色器 (Vertex Shader) 的 SIMT 执行与属性插值准备
------------------------------------------------------------------------

解包完成的顶点属性被分派至可编程计算核心（SM / CU）的物理寄存器堆中，启动顶点着色器（VS）的并行执行。

顶点着色器的核心物理职责
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. **几何空间流转**：通过模型-观察-投影矩阵（MVP）将顶点从局部对象空间变换至齐次裁剪空间：
   
   .. math::
      \mathbf{P}_{	ext{clip}} = \mathbf{M}_{	ext{proj}} \cdot \mathbf{M}_{	ext{view}} \cdot \mathbf{M}_{	ext{model}} \cdot \mathbf{P}_{	ext{local}}

2. **骨骼蒙皮矩阵加权融合 (Linear Blend Skinning - LBS)**：
   对于骨骼动画网格，顶点根据关节索引（Bone Indices）与权重（Bone Weights）对多个骨骼矩阵进行线性混合：
   
   .. math::
      \mathbf{P}_{	ext{skinned}} = \sum_{i=0}^3 w_i \cdot \mathbf{M}_{	ext{bone}[i]} \cdot \mathbf{P}_{	ext{local}}

3. **输出系统值与可插值属性**：
   - 必须输出系统值语义 `SV_Position`（裁剪空间四维齐次坐标）；
   - 输出法线、切线、UV 坐标与顶点颜色至后级硬件插值器寄存器（Interpolator Registers）。

11.3 齐次视锥体多边形裁剪 (Homogeneous Frustum Clipping)
------------------------------------------------------------------------

顶点着色器输出的齐次裁剪坐标 $\mathbf{P}_c = [x_c, y_c, z_c, w_c]^T$ 必须在**进入光栅化器之前完成空间裁剪**。

为何绝对禁止在透视除法后进行裁剪？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

若在透视除法后（即在 NDC 空间）执行裁剪，对于位于摄像机后方（$w_c \le 0$）的顶点，其坐标 $x_c / w_c$ 将发生符号翻转或除零无穷大异常，使得原本在相机后方的物体被错误地投影并镜像到屏幕前方。

因此，**几何裁剪必须且只能在四维齐次裁剪空间内完成**。

视锥体六平面的齐次不等式组
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在齐次空间中，一个点位于视锥体内部的充要条件是同时满足以下 6 个线性不等式（以 DirectX / Vulkan $z_{	ext{ndc}} \in [0, 1]$ 规范为例）：

.. math::

   \begin{cases}
   -w_c \le x_c \le w_c & (	ext{左 / 右裁剪平面}) \
   -w_c \le y_c \le w_c & (	ext{下 / 上裁剪平面}) \
   0 \le z_c \le w_c    & (	ext{近 / 远裁剪平面})
   \end{cases}

Sutherland-Hodgman 多边形裁剪算法
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当一个三角形跨越视锥体边界平面时，硬件裁剪单元采用 **Sutherland-Hodgman 算法**对多边形进行逐平面剪切：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |             Sutherland-Hodgman 齐次空间线段求交与多边形分裂             |
   +-------------------------------------------------------------------------+

              P1 (视锥体内, w1)
              +
              | \
              |  \
   ===========+===+=========================== [ 裁剪平面边界: x_c = w_c ]
              |    \
              |     \
              +------+
             P0      P2 (视锥体外, w2)
             (外)

- **边与平面相交参数 $t$ 的精确代数解**：
  设线段上任意点为 $\mathbf{P}(t) = (1-t)\mathbf{P}_1 + t\mathbf{P}_2$。在右裁剪平面 $x_c = w_c$ 上，满足：
  
  .. math::
     (1-t)x_1 + tx_2 = (1-t)w_1 + tw_2 \implies t = \frac{w_1 - x_1}{(w_1 - x_1) - (w_2 - x_2)}

- 三角形被单平面截断后生成一个四边形，硬件将其重新三角化（Retriangulation）为两个新三角形，所有顶点属性（UV、法线、颜色）均按参数 $t$ 线性插值生成。

保护带裁剪 (Guard-Band Clipping) 硬件加速
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

真实的现代 GPU 硬件内置了远大于屏幕视口的**保护带区域（Guard-Band）**（通常为视口尺寸的 4~8 倍）。对于超出视口但位于 Guard-Band 内部的图元，硬件完全跳过昂贵的几何裁剪与顶点生成，直接交由光栅化器在屏幕像素边界进行像素级快速丢弃（Scissor Test），极大释放了几何前端算力。

11.4 图元装配 (Primitive Assembly) 与多边形重构状态机
------------------------------------------------------------------------

裁剪完成后，顶点流进入图元装配阶段，根据拓扑模式（Primitive Topology）重构图元连接关系：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       常见拓扑装配模式数据流                            |
   +-------------------------------------------------------------------------+

   [ 1. 三角形列表 (Triangle List) ]
   输入索引: [0, 1, 2], [3, 4, 5] ---> 独立装配为 Triangle(0,1,2) 与 Triangle(3,4,5)

   [ 2. 三角形带 (Triangle Strip) ]
   输入索引: [0, 1, 2, 3, 4] ---> 装配为 Tri(0,1,2), Tri(2,1,3), Tri(2,3,4)...
   * 硬件状态机自动交替反转缠绕顺序，保证所有三角形法线朝向一致。

   [ 3. 图元重启机制 (Primitive Restart) ]
   当遇到特殊索引值 0xFFFF 或 0xFFFFFFFF 时，状态机立即切断当前 Strip 并开启新图元。

视口变换 (Viewport Transformation)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

图元在执行透视除法得到 NDC 坐标后，通过视口变换映射至最终的屏幕物理像素坐标：

.. math::

   x_{	ext{screen}} = \frac{x_{	ext{ndc}} + 1}{2} \cdot 	ext{Width} + X_{	ext{min}}, \quad y_{	ext{screen}} = \frac{1 - y_{	ext{ndc}}}{2} \cdot 	ext{Height} + Y_{	ext{min}}

11.5 背面剔除 (Backface Culling) 与屏幕空间面积判定
------------------------------------------------------------------------

在将三角形送入光栅化像素扫描之前，硬件执行**背面剔除（Backface Culling）**，以剔除背向摄像机的多边形（在闭合实体网格中，背面多边形占总量的 50%）。

屏幕空间有向面积 (Signed Area) 判定法则
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

硬件无需进行复杂的三维空间法线与视线点积计算，而是直接在投影后的二维屏幕像素空间计算三角形顶点的**有向面积（Signed Area）**：

.. math::

   2A = (x_1 - x_0)(y_2 - y_0) - (y_1 - y_0)(x_2 - x_0) = \det \begin{bmatrix} x_1 - x_0 & x_2 - x_0 \ y_1 - y_0 & y_2 - y_0 \end{bmatrix}

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                 屏幕空间二维叉乘判定三角形顶点缠绕方向                  |
   +-------------------------------------------------------------------------+

        P1(x1, y1)                          P0(x0, y0)
         /\                                  /\
        /  \   逆时针缠绕 (CCW): 2A > 0     /  \   顺时针缠绕 (CW): 2A < 0
       /    \  --> 正面 (Front Face)       /    \  --> 背面 (Back Face)
      /______\                            /______\
     P0(x0, y0)   P2(x2, y2)             P2(x2, y2)   P1(x1, y1)

- **硬件判定准则**：
  若当前管线配置为剔除背面（`CullMode = BACK`，且正面定义为 `CCW`）：
  - 当 $2A > 0$ 时，判定为正面，保留该图元进入光栅化阶段；
  - 当 $2A \le 0$（顺时针或退化为一条线的退化三角形）时，硬件在 **1 个时钟周期内直接抛弃该图元**，彻底消除后续像素着色开销。

小结与下章导读
------------------------------------------------------------------------

本章从硬件微架构出发，解构了输入装配器（IA）的顶点属性解包、顶点着色器的 SIMT 执行、齐次裁剪空间视锥体多边形裁剪（Sutherland-Hodgman 算法与 Guard-Band 机制）、图元装配状态机以及基于屏幕空间二维有向面积的背面剔除原理。
