========================================================================
Chapter 19: 阴影生成技术全景：Shadow Mapping、CSM、PCF 与 PCSS
========================================================================

.. note:: 前置背景与认知承接
   前一章深入剖析了次表面散射（SSS）的 BSSRDF 物理模型、Jensen 偶极子扩散、屏幕空间 SSSSS 与预积分皮肤着色。在三维渲染中，光照决定了物体表面的明暗，而阴影（Shadows）则提供了物体与环境的空间几何接触感、深度感知与场景遮蔽关系。实时阴影算法的核心挑战在于：在有限的显存与计算预算下，克服走样（Aliasing）、自遮挡（Shadow Acne）、漏光（Peter Panning）与硬阴影生硬感。本章将从经典阴影贴图（Shadow Mapping）的两阶段流水线出发，系统推导透视走样的几何成因、斜率缩放深度偏移（Slope-Scaled Depth Bias）、级联阴影贴图（CSM）的平截头体最佳分割数学模型、百分比接近滤波（PCF）的硬件采样支持，以及基于面积光源物理半影的百分比接近软阴影（PCSS）算法。

19.1 经典 Shadow Mapping 两阶段流水线与走样缺陷
------------------------------------------------------------------------

Lance Williams 于 1978 年提出的**阴影映射（Shadow Mapping）**算法，是现代所有图形 API 与实时渲染管线实现动态阴影的绝对基石。

两阶段渲染流水线微架构
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Shadow Mapping 将阴影判定转化为图像空间的深度可见性比对问题，分为两个严格解耦的渲染阶段：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  经典 Shadow Mapping 两阶段渲染流水线                   |
   +-------------------------------------------------------------------------+

   [ Pass 1: 光源深度通道 (Light Depth Pass) ]
   * 将虚拟摄像机置于光源位置，视锥体对准照射区域
   * 渲染场景几何图元，关闭颜色写出，仅将深度值写入阴影贴图 (Shadow Map, 如 D32_FLOAT)
   ---------------------------------------------------------------------------
   [ Pass 2: 主相机着色通道 (Main Camera Shading Pass) ]
   * 从玩家相机视口正常渲染场景几何
   * 对每个像素世界坐标 P_world，通过光源视图-投影矩阵变换至光照裁剪空间:
        P_light_clip = LightViewProjMatrix * P_world
        P_light_ndc  = P_light_clip.xyz / P_light_clip.w
        UV_shadow    = P_light_ndc.xy * 0.5 + 0.5
        z_current    = P_light_ndc.z
   * 采样 Shadow Map 获取该方向上离光源最近的阻挡深度 z_shadow = ShadowMap.Sample(UV_shadow)
   * 深度比较判定可见性:
        Visibility = (z_current <= z_shadow + Bias) ? 1.0 (光照区) : 0.0 (阴影区)

阴影走样的两大物理成因
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table:: 阴影贴图走样类型与几何物理成因
   :widths: 25 35 40
   :header-rows: 1
   :class: tight-table

   * - 走样分类
     - 几何物理成因
     - 视觉失真表现
   * - **透视走样
(Perspective Aliasing)**
     - 主相机近处的一个屏幕像素（Pixel），在光源视角下投影覆盖了 Shadow Map 上的大片纹素（Texel 欠采样）
     - 画面近处的阴影边缘呈现严重的锯齿状阶梯马赛克
   * - **投影走样
(Projective Aliasing)**
     - 当光源照射方向与接收面法线接近垂直（掠射角，$\vec{n} \cdot \vec{l} \approx 0$）时，光照视锥被剧烈几何拉伸
     - 阴影在斜坡或平地上被拉长变形，产生严重的拉伸模糊与失真

19.2 自遮挡 (Shadow Acne) 与漏光 (Peter Panning) 的偏移解算
------------------------------------------------------------------------

由于 Shadow Map 采用离散的二维纹素网格记录深度，每个纹素只能记录一个恒定的深度平面。当连续的光滑曲面被离散化后，必然导致计算出的像素深度在半个纹素区域内大于 Shadow Map 中的记录深度，从而在向光面上产生密密麻麻的条纹黑斑——**自遮挡（Shadow Acne）**。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       Shadow Acne 与 Peter Panning 物理机制             |
   +-------------------------------------------------------------------------+

   物理光滑斜面 --------------------------> / / / / / / / / / (实际几何表面)
   Shadow Map 离散阶梯深度:               +---+
                                          |   |   +---+
                                          |   |   |   |   +---+
   * Acne 区域: 几何表面高于阶梯 -> 误判为阴影！(产生斑马纹黑斑)
   ---------------------------------------------------------------------------
   * 错误解法: 施加过大的常数偏移 Constant Bias
   -> 整个阴影在空间中被推后，导致阴影脱离物体底部悬空 (Peter Panning 漏光!)

斜率缩放深度偏移 (Slope-Scaled Depth Bias - SSDB)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

为了在消除 Acne 的同时杜绝 Peter Panning，现代 GPU 硬件内置了基于多边形局部几何斜率的**斜率缩放深度偏移（Slope-Scaled Depth Bias）**：

.. math::

   	ext{Slope} = \max\left( \left| \frac{\partial z}{\partial x} \right|, \; \left| \frac{\partial z}{\partial y} \right| \right) = 	an 	heta = \frac{\sqrt{1 - (\vec{n} \cdot \vec{l})^2}}{\vec{n} \cdot \vec{l}}

.. math::

   	ext{Total Bias} = 	ext{ConstantBias} + 	ext{SlopeScaleFactor} 	imes 	ext{Slope}

- **垂直顺光面**（$\vec{n} \cdot \vec{l} \approx 1$）：斜率接近 0，仅施加极小的 `ConstantBias`，彻底保留脚底精准接触阴影；
- **极端掠射斜面**（$\vec{n} \cdot \vec{l} 	o 0$）：斜率激增，自动施加高阶偏移，彻底消除斑马纹。

法线几何偏移 (Normal Offset Bias) 算法
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

除了深度维度的偏移外，在顶点或像素计算光照坐标时，将采样原点沿世界空间法线方向微弱偏移，能显著增强阴影稳定性：

.. code-block:: hlsl

   // 基于法线微平移消除自遮挡
   float3 normalOffset = worldNormal * (normalBias * (1.0f - saturate(dot(worldNormal, lightDir))));
   float4 shadowPos = mul(float4(worldPos + normalOffset, 1.0f), LightViewProj);

19.3 级联阴影贴图 (CSM - Cascaded Shadow Maps) 几何架构
------------------------------------------------------------------------

对于太阳光（方向平行光），若用单张 $4096 	imes 4096$ 的 Shadow Map 覆盖数平方公里的开阔游戏场景，近处阴影的透视走样将不堪入目。**级联阴影贴图（Cascaded Shadow Maps - CSM）**是工业界解决大场景平行光走样的标准架构。

CSM 视锥体多级分割原理
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

CSM 将主相机的视锥体沿深度方向切割为 $N$ 个（通常为 3~4 个）子区间（Cascades）。每个子视锥体分别构建一个紧密包围的正交投影矩阵（Orthographic Box），生成独立的 Shadow Map：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                      CSM 视锥体多级级联分割与空间分配                   |
   +-------------------------------------------------------------------------+

   主相机视角:
   [ 视点 Camera ]
         \     Cascade 0: 近景区间 (0~10m, 分辨率极高, 像素密度 > 100 texel/m)
          \+-------------+
           \   Cascade 1: 中景区间 (10~40m, 分辨率均衡)
            \+-------------------+
             \   Cascade 2: 远景区间 (40~150m, 分辨率适中)
              \+---------------------------+
               \   Cascade 3: 超远景区间 (150~500m, 覆盖广阔地貌)
                +-------------------------------------+

平截头体最佳分割数学模型 (Practical Split Scheme)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

若单纯按线性均匀切割，近景分配的采样率严重不足；若单纯按对数等比切割，远景分段过于稀疏。Engel 提出的**混合对数分割模型**构成了工业界的最优解：

.. math::

   z_i = \lambda \cdot z_{	ext{near}} \left( \frac{z_{	ext{far}}}{z_{	ext{near}}} \right)^{\frac{i}{N}} + (1 - \lambda) \left( z_{	ext{near}} + \frac{i}{N}(z_{	ext{far}} - z_{	ext{near}}) \right)

- 权重因子 $\lambda \in [0.7, 0.9]$：在保证近景具备极高对数分辨率的同时，兼顾远景的平滑过渡。

Texel 锁定 (Texel Snapping) 消除相机移动爬行闪烁
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当玩家相机平移时，CSM 的正交包围盒随之连续移动，导致 Shadow Map 的采样网格与场景几何不断发生微小的亚像素错位，阴影边缘产生剧烈的抖动爬行（Shimmering Artifacts）。

**Texel 锁定算法**：将光源投影矩阵的原点强制量化（Snap）到单个 Shadow Map 纹素大小的整数倍：

.. math::

   \Delta x_{	ext{world}} = \frac{	ext{CascadeWidth}}{	ext{ShadowMapResolution}}, \quad \mathbf{P}_{	ext{snapped}} = 	ext{floor}\left( \frac{\mathbf{P}_{	ext{light}}}{\Delta x_{	ext{world}}} \right) 	imes \Delta x_{	ext{world}}

19.4 百分比接近滤波 (PCF - Percentage Closer Filtering)
------------------------------------------------------------------------

传统纹理采样的双线性插值直接作用于颜色值。若对 Shadow Map 的深度值直接执行双线性插值，插值后的深度与当前像素比较依然是非 0 即 1 的布尔值，根本无法消除锯齿。

PCF 核心数学思想：先比较，后滤波
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Reeves 等人提出的 **百分比接近滤波（Percentage-Closer Filtering - PCF）** 彻底颠覆了滤波顺序：
**在当前像素周围采集 $M 	imes M$ 个相邻纹素，先让每个纹素独立执行深度比较生成二值可见性（0 或 1），再对这组可见性结果进行加权平均**，输出 $0.0 \sim 1.0$ 的平滑阴影率：

.. math::

   	ext{Visibility}_{	ext{PCF}}(x, y) = \frac{1}{(2k + 1)^2} \sum_{u=-k}^{k} \sum_{v=-k}^{k} 	ext{Step}\Big( 	ext{ShadowMap}(x+u, y+v) - (z_{	ext{current}} - 	ext{Bias}) \Big)

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       3x3 PCF 滤波矩阵采样计算实例                      |
   +-------------------------------------------------------------------------+

   3x3 深度比较二值结果:
   [ 0 (遮挡) ] [ 1 (光照) ] [ 1 (光照) ]
   [ 0 (遮挡) ] [ 0 (遮挡) ] [ 1 (光照) ]  => 共有 4 个点在光照区，5 个点被遮挡
   [ 0 (遮挡) ] [ 0 (遮挡) ] [ 1 (光照) ]

   最终平滑阴影因子 = 4 / 9 = 0.444 (呈现平滑半阴影过渡)

GPU 硬件级 SamplerComparisonState 支持
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

现代 GPU 硬件内置了专用阴影采样器（DirectX `SampleCmpLevelZero` / OpenGL `sampler2DShadow`）。硬件纹理单元在单次指令中自动完成 4 个相邻纹素的深度比较，并在硬件内部直接完成双线性加权平均，零额外 ALU 开销实现原生 2x2 PCF！

19.5 接触硬化软阴影 (PCSS - Percentage-Closer Soft Shadows)
------------------------------------------------------------------------

物理世界中不存在绝对的点光源，真实的面光源（Area Light）必然在物体背后投射出包含**本影（Umbra）**与**半影（Penumbra）**的软阴影。

面积光源半影几何模型
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

根据初等几何相似三角形定理，半影宽度（Penumbra Width）严格取决于**遮挡物到光源的距离 $d_{	ext{blocker}}$** 与 **接收面到光源的距离 $d_{	ext{receiver}}$**：

.. math::

   w_{	ext{penumbra}} = w_{	ext{light}} \cdot \frac{d_{	ext{receiver}} - d_{	ext{blocker}}}{d_{	ext{blocker}}}

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                      PCSS 面积光源物理半影相似三角形模型                |
   +-------------------------------------------------------------------------+

          [ 物理面光源 Area Light (宽度: w_light) ]
                 \                     /
                  \                   /
                   \  d_blocker      /
                    \               /
             ========[ 遮挡物 Blocker ]========
                      \           /
                       \         /  d_receiver - d_blocker
                        \       /
   ======================+=====+====================== [ 受光面 Receiver ]
                         |<-w->|  (半影宽度 w_penumbra: 遮挡物越近越硬，越远越软)

PCSS 经典三步算法流程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. list-table:: PCSS 算法三步执行状态机
   :widths: 20 40 40
   :header-rows: 1
   :class: tight-table

   * - 步骤编号
     - 阶段算法职责
     - 物理微架构执行
   * - **Step 1: 遮挡物搜索
(Blocker Search)**
     - 在当前像素周围设定搜索半径 $w_{	ext{search}} = w_{	ext{light}} \cdot \frac{d_{	ext{receiver}} - z_{	ext{near}}}{d_{	ext{receiver}}}$
     - 采样泊松盘分布点，仅对判定为遮挡的采样点求深度平均值，得到平均遮挡深度 $d_{	ext{blocker}}$
   * - **Step 2: 半影宽度解算
(Penumbra Estimation)**
     - 代入相似三角形公式计算当前像素对应的动态滤波半径
     - $w_{	ext{filter}} = w_{	ext{light}} \cdot \frac{d_{	ext{receiver}} - d_{	ext{blocker}}}{d_{	ext{blocker}}}$
   * - **Step 3: 自适应 PCF 滤波
(Filtering)**
     - 以 $w_{	ext{filter}}$ 为动态核半径执行泊松盘随机采样 PCF 深度测试
     - 动态自适应实现接触面锐利（Contact Hardening）而远端极度柔和的物理真实软阴影！

小结与下章导读
------------------------------------------------------------------------

本章从 Shadow Mapping 两阶段流水线出发，推导了透视走样成因与斜率缩放深度偏移（SSDB）的解算几何，系统解构了级联阴影（CSM）的混合对数最佳分割、PCF 硬件采样加权机制，以及基于相似三角形半影推导的 PCSS 接触硬化软阴影算法。

在掌握了局部光照、微表面材质、次表面散射与动态阴影技术后，材质系统的最后一块物理拼图是纹理数据的高效存储与显存交换——**纹理硬件解压与采样架构：BCn/ASTC 编码算法、各向异性过滤与虚拟纹理 (VT)**。下一章我们将深入 GPU 片上纹理缓存（Texture Cache）、现代块压缩算法（BC1~BC7, ASTC 硬件解压引擎）、Mipmap 各向异性过滤椭圆脚印足迹解算，以及突破物理显存限制的虚拟纹理（Virtual Texturing / Nanite 纹理底座）架构。
