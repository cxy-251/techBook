16.1 光的物理本性与辐射度量学 (Radiometry) 物理量体系
------------------------------------------------------------------------

在计算机图形学中，可见光（波长约 $380\,	ext{nm} \sim 780\,	ext{nm}$）被建模为在空间中沿直线传播的电磁辐射能量流。为了量化光能的发射、传播、散射与接收，必须建立一套不依赖于人眼主观感知的客观物理度量系统——**辐射度量学（Radiometry）**。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       辐射度量学五大核心物理量金字塔                    |
   +-------------------------------------------------------------------------+

   [ 1. 辐射能 Q (Radiant Energy) ]  -- 能量总量 (Joules, J)
        |
        v  (单位时间导数 d/dt)
   [ 2. 辐射通量 / 功率 Φ (Radiant Flux) ]  -- 能量传输速率 (Watts, W = J/s)
        |
        +-----------------------------------+
        |                                   |
        v (对微分立体角求导 d/dω)            v (对微分表面积求导 d/dA)
   [ 3. 辐射强度 I (Radiant Intensity) ]   [ 4. 辐照度 E (Irradiance) ]
     点光源方向密度 (W/sr)                  表面接收功率密度 (W/m²)
        |                                   |
        +-----------------+-----------------+
                          |
                          v (对投影面积与立体角联合求导 d²Φ / (dA cosθ dω))
                   [ 5. 辐射率 L (Radiance) ]
                     沿特定光线传播的能量密度 (W / (m² · sr))
                     **图形渲染管线中像素计算的唯一绝对核心量！**

微分立体角 (Differential Solid Angle) 的数学推导
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

立体角（Solid Angle, $\omega$）是二维平面角在三维空间中的投影推广，定义为空间锥体在单位球面上截取的表面积，单位为球面度（Steradian, $	ext{sr}$）。

在球坐标系 $(r, 	heta, \phi)$ 中，极角 $	heta \in [0, \pi]$，方位角 $\phi \in [0, 2\pi]$。单位球面（$r=1$）上的微分表面积元即为微分立体角 $d\omega$：

.. math::

   d\omega = \sin	heta\,d	heta\,d\phi

对全上半球（Hemisphere, $\Omega^+$）进行立体角全积分：

.. math::

   \int_{\Omega^+} d\omega = \int_{0}^{2\pi} d\phi \int_{0}^{\frac{\pi}{2}} \sin	heta\,d	heta = 2\pi \cdot [-\cos	heta]_{0}^{\frac{\pi}{2}} = 2\pi\,	ext{sr}

对整个全封闭球体进行全积分，总立体角为 $4\pi\,	ext{sr}$。

为什么辐射率 $L$ 是光线追踪与光栅化着色的唯一基本量？
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

1. **光线传播的不变性（Conservation of Radiance along Rays）**：在无散射的真空或均质空气中，沿任意光线传播的辐射率 $L$ 随传播距离保持严格恒定（不随距离平方衰减！）；
2. **传感器响应正比性**：无论是人眼视网膜感光细胞、相机 CMOS 传感器像素，还是 GPU 帧缓冲中的单个像素颜色，其输出电荷响应均严格正比于入射到该像素视锥微元内的**辐射率 $L$**。

16.2 表面投影面积因子与朗伯余弦定律 (Lambert's Cosine Law)
------------------------------------------------------------------------

当平行光束以倾斜角 $	heta$ 照射至受光表面时，相同的光通量 $\Phi$ 被摊薄覆盖到更大的物理表面积上。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                   光束投影面积扩张与能量稀释几何机理                    |
   +-------------------------------------------------------------------------+

              \   光束入射方向 l   /
               \                 /
                \   截面面积     /
       ----------+-------------+----------  <-- 垂直光束截面面积: dA_perp
                  \     θ     /
                   \         /
       -------------+-------+-------------  <-- 倾斜受光物理表面: dA
                     \     /
                      \   /
                       \ /
                        v
       表面法线 n 与光线反方向 l 的夹角为 θ:
       几何投影关系: dA_perp = dA * cosθ = dA * (n · l)

因此，受光表面接收到的微分辐照度 $dE$ 为：

.. math::

   dE = \frac{d\Phi}{dA} = \frac{d\Phi}{\frac{dA^\perp}{\cos	heta}} = L_i \cos	heta\,d\omega = L_i\,(\mathbf{n} \cdot \mathbf{l})\,d\omega

这就是著名的 **朗伯余弦定律（Lambert's Cosine Law）**：表面接收的能量密度直接正比于表面法线 $\mathbf{n}$ 与入射光方向 $\mathbf{l}$ 的点积 $\max(\mathbf{n} \cdot \mathbf{l}, 0)$。

点光源的距离平方反比定律 (Inverse-Square Law)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于一个向全空间均匀发射总功率为 $\Phi$ 的理想点光源，在距离点光源 $r$ 处的空间中，其能量均匀散布在半径为 $r$ 的球面上（球表面积 $A = 4\pi r^2$）。该距离处的空间辐照度 $E$ 满足：

.. math::

   E(r) = \frac{\Phi}{4\pi r^2} = \frac{I}{r^2}

结合表面倾斜角 $	heta$，物体表面接收到的辐照度完整方程为：

.. math::

   E = \frac{I}{r^2} \cos	heta = \frac{I}{r^2} (\mathbf{n} \cdot \mathbf{l})

16.3 双向反射分布函数 (BRDF) 的严格数学定义与物理约束
------------------------------------------------------------------------

当光线照射至不透明物体表面时，一部分光子在表面微观粗糙界面发生反射，另一部分光子折射进入介质浅层并被多次散射后重新射出表面。为了精确描述表面对不同方向入射光的反射能力分布，引入了**双向反射分布函数（Bidirectional Reflectance Distribution Function - BRDF）**。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                       BRDF 双向反射微分几何系统                         |
   +-------------------------------------------------------------------------+

                                 法线 n
                                   ^
                                   |      出射视线方向 ω_o (θ_o, φ_o)
          入射光线方向 ω_i (θ_i, φ_i) \   /
                                    \ /
        ----------------------------- x ----------------------------- (表面微元 dA)
                                   / | \
                                  /  |  \
                                 半球微观散射空间 Ω+

BRDF 的严格定义方程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

BRDF 定义为沿着出射方向 $\omega_o$ 的**微分出射辐射率 $dL_o$** 与沿着入射方向 $\omega_i$ 投射至表面微元的**微分入射辐照度 $dE_i$** 的比值：

.. math::

   f_r(\mathbf{x}, \omega_i, \omega_o) = \frac{dL_o(\mathbf{x}, \omega_o)}{dE_i(\mathbf{x}, \omega_i)} = \frac{dL_o(\mathbf{x}, \omega_o)}{L_i(\mathbf{x}, \omega_i) \cos	heta_i\,d\omega_i}

- **单位解析**：出射辐射率单位为 $	ext{W}/(	ext{m}^2\cdot	ext{sr})$，入射辐照度单位为 $	ext{W}/	ext{m}^2$，因此 **BRDF 的物理量纲严格为球面度的倒数（$	ext{sr}^{-1}$）**，而不是无量纲系数！

物理可信 BRDF 必须遵循的三大基本物理定律
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

任意一个符合物理真实性的材质反射模型（Physically Plausible BRDF），在数学上必须严格无条件满足以下三项定律：

1. **非负性 (Positivity)**：
   表面无法凭空创造负能量或吸收超出范围的光子：

   .. math::

      f_r(\omega_i, \omega_o) \ge 0, \quad \forall \omega_i, \omega_o \in \Omega^+

2. **亥姆霍兹互易律 (Helmholtz Reciprocity)**：
   依据光学光路可逆性原理，对调入射光路 $\omega_i$ 与出射视线 $\omega_o$，反射比率保持完全不变：

   .. math::

      f_r(\omega_i, \omega_o) = f_r(\omega_o, \omega_i)

   - 该性质是光线追踪中双向路径追踪（BDPT）与光子映射（Photon Mapping）算法正确收敛的理论前提。

3. **能量守恒定律 (Energy Conservation)**：
   反射出半球的总辐射通量，绝不能超过入射的总辐射通量。对于任意入射方向 $\omega_i$，半球方向反射率（Directional-Hemispherical Reflectance, $\rho(\omega_i)$）必须小于等于 1.0：

   .. math::

      \rho(\omega_i) = \int_{\Omega^+} f_r(\omega_i, \omega_o) \cos	heta_o\,d\omega_o \le 1.0, \quad \forall \omega_i \in \Omega^+

理想漫反射 (Lambertian) BRDF 的能量守恒推导
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于一个理想的各向同性漫反射表面，其反射光在半球空间各个出射方向上均匀分布，因此其 BRDF 是一个与 $\omega_o$ 无关的常数 $f_r(\omega_i, \omega_o) = c_{	ext{diff}}$。
设材质的漫反射反照率（Albedo）为 $\rho \in [0, 1]$，代入能量守恒全积分方程：

.. math::

   \rho = \int_{\Omega^+} c_{	ext{diff}} \cos	heta_o\,d\omega_o = c_{	ext{diff}} \int_{0}^{2\pi} d\phi_o \int_{0}^{\frac{\pi}{2}} \cos	heta_o \sin	heta_o\,d	heta_o

利用三角恒等式 $\cos	heta\sin	heta = \frac{1}{2}\sin(2	heta)$ 积分：

.. math::

   \rho = c_{	ext{diff}} \cdot 2\pi \cdot \left[ \frac{1}{2} \sin^2	heta_o \right]_{0}^{\frac{\pi}{2}} = c_{	ext{diff}} \cdot \pi

由此严格推导出理想朗伯漫反射的经典公式：

.. math::

   f_{r,	ext{Lambert}} = \frac{\rho}{\pi}

- **关键结论**：漫反射着色器中除以 $\pi$ 不是为了色彩调优，而是为了在半球积分下严格达成能量守恒的物理必然结果！

16.4 渲染方程 (The Rendering Equation) 全局解析
------------------------------------------------------------------------

1986 年，James Kajiya 在 SIGGRAPH 论文中提出了现代图形学的统摄大厦——**渲染方程（The Rendering Equation）**。它将表面自发光、直接光照、间接光照与材质反射完整统一在一个积分方程中：

.. math::

   L_o(\mathbf{x}, \omega_o) = L_e(\mathbf{x}, \omega_o) + \int_{\Omega^+} f_r(\mathbf{x}, \omega_i, \omega_o)\,L_i(\mathbf{x}, \omega_i)\,(\mathbf{n} \cdot \omega_i)\,d\omega_i

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                        渲染方程各项物理构成拆解                         |
   +-------------------------------------------------------------------------+

     L_o(x, ω_o)   : 物体表面点 x 沿视线方向 ω_o 射出的总辐射率 (最终呈现在屏幕上的像素值)
          =
     L_e(x, ω_o)   : 物体自身发出的自发光辐射率 (Emissive Radiance，如荧光灯、熔岩)
          +
     ∫_{Ω+}        : 对点 x 上半球空间所有入射方向 ω_i 的连续积分
     f_r(x, ω_i, ω_o): 该表面材质在特定入射角与出射角下的 BRDF 反射响应函数
     L_i(x, ω_i)   : 从方向 ω_i 射入点 x 的入射光辐射率
     (n · ω_i)     : 朗伯余弦投影因子 cosθ_i (能量几何稀释项)
     dω_i          : 微分入射立体角

渲染方程的 Fredholm 第二类积分方程本性
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

入射辐射率 $L_i(\mathbf{x}, \omega_i)$ 并不是孤立给定的常数，它来自于场景中另一处表面点 $\mathbf{x}'$ 沿方向 $-\omega_i$ 射出的出射辐射率：

.. math::

   L_i(\mathbf{x}, \omega_i) = L_o(	ext{raycast}(\mathbf{x}, \omega_i), -\omega_i)

- **无限递归链**：$L_o$ 出现在等式左侧，同时通过 $L_i$ 隐式嵌套在等式右侧的积分号内！这种递归依赖构成了全局光照（Global Illumination）的本质：光线在场景多表面之间经历无数次反弹（Bounce），产生漫反射颜色溢出（Color Bleeding）、焦散（Caustics）与环境遮蔽（AO）。

16.5 工业级着色器中的单位换算与物理量落地
------------------------------------------------------------------------

在实时渲染管线（DirectX 12 / Vulkan / Unreal Engine 5 / Unity HDRP）中，光栅化像素着色器无法在每一帧实时执行连续半球数值积分，而是将积分分解为离散点光源（Punctual Lights）与基于图像的环境光照（IBL）。

离散点光源的狄拉克函数退化与着色计算
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

对于一个具有发光强度 $I_{	ext{light}}$（单位 $	ext{cd} = 	ext{lm}/	ext{sr}$）的理想点光源，其入射辐射率分布退化为一个空间狄拉克 $\delta$ 函数：$L_i(\omega) = I_{	ext{light}} \frac{\delta(\omega - \omega_{	ext{light}})}{r^2}$。
代入渲染方程积分，积分号被瞬时消除，退化为高效的单次着色代数乘法：

.. math::

   L_o(\mathbf{x}, \omega_o) = f_r(\mathbf{x}, \omega_{	ext{light}}, \omega_o) \cdot \frac{I_{	ext{light}}}{r^2} \cdot \max(\mathbf{n} \cdot \mathbf{l}, 0)

.. code-block:: hlsl

   // HLSL 工业级物理点光源单次着色解算实现
   struct PunctualLight {
       float3 PositionWS;
       float3 IntensityLumens; // 光通量 (lm)
       float  AttenuationRadius;
   };

   float3 EvaluateDirectPunctualLight(
       float3 WorldPos,
       float3 NormalWS,
       float3 ViewDirWS,
       float3 Albedo,
       float  Roughness,
       float  Metallic,
       PunctualLight Light
   ) {
       float3 LightVector = Light.PositionWS - WorldPos;
       float DistanceSq = dot(LightVector, LightVector);
       float Distance = sqrt(DistanceSq);
       float3 LightDirWS = LightVector / max(Distance, 0.0001f);

       float NdotL = saturate(dot(NormalWS, LightDirWS));
       if (NdotL <= 0.0f) return float3(0.0f, 0.0f, 0.0f);

       // 物理平方反比衰减与平滑窗函数截断 (防止除零与无限扩散)
       float DistanceAtten = 1.0f / max(DistanceSq, 0.01f * 0.01f);
       float WindowFactor = saturate(1.0f - pow(Distance / Light.AttenuationRadius, 4.0f));
       float SmoothAtten = DistanceAtten * (WindowFactor * WindowFactor);

       // 辐射强度 (W/sr 或 cd) = 总光通量 / 4π
       float3 RadiantIntensity = (Light.IntensityLumens / (4.0f * 3.14159265f)) * SmoothAtten;

       // 评估表面 BRDF (将在下一章深入微表面模型解算)
       float3 BRDF_Value = Albedo / 3.14159265f; // 此处以纯朗伯漫反射为例

       // 最终反射出射辐射率 L_o
       float3 OutRadiance = BRDF_Value * RadiantIntensity * NdotL;
       return OutRadiance;
   }

物理光学单位与 HDR 帧缓冲精度
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

现代物理渲染管线统一采用**高动态范围（High Dynamic Range - HDR）**光照单位：
- **太阳光直射照度**：可达 $100,000\,	ext{Lux} = 100,000\,	ext{lm}/	ext{m}^2$；
- **室内人工照明照度**：约 $300 \sim 500\,	ext{Lux}$；
- **夜间月光照度**：仅约 $0.01 \sim 0.1\,	ext{Lux}$。

由于真实世界的明暗动态范围跨越 $10^7$ 个数量级，渲染管线的中间颜色目标（Render Target）必须使用 `R11G11B10_FLOAT` 或 `RGBA16F` 半精度/单精度浮点纹理存储，并通过虚拟相机曝光公式（EV100 自动曝光）将物理辐射率映射压缩至 LDR 显示设备的 $[0, 1]$ 范围。

小结与下章导读
------------------------------------------------------------------------

本章从电磁辐射能的物理本质出发，系统推导了辐射度量学五大核心物理量（辐射能、通量、强度、辐照度、辐射率）、微分立体角球坐标积分与朗伯余弦几何稀释定律，严格证明了双向反射分布函数（BRDF）的非负性、亥姆霍兹互易律与能量守恒三大物理准则，并建立了 Kajiya 渲染方程的微积分全貌与现代着色器点光源离散求值实现。
