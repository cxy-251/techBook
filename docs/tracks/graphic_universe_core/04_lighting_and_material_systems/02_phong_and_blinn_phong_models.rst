========================================================================
Chapter 17: 经典经验光照模型：Lambert 漫反射、Phong 高光与 Blinn-Phong 近似
========================================================================

.. note:: 前置背景与认知承接
   前一章系统建立了辐射度量学五大物理量（辐射能、通量、强度、辐照度、辐射率）、双向反射分布函数（BRDF）的物理定律（非负性、互易律、能量守恒）以及 Kajiya 渲染方程。在计算机图形学发展的早期阶段（20 世纪 70 年代至 21 世纪初），受限于微处理器计算能力与显卡固定渲染管线的硬件制约，实时渲染无法直接求解复杂的物理微表面积分，而是广泛采用了**基于直觉观察与经验拟合的光照模型（Empirical Shading Models）**。本章将系统解构经典 Lambert 漫反射与半兰伯特（Half-Lambert）改进、Phong 视线反射高光模型、Jim Blinn 提出的半程向量（Halfway Vector）微表面几何逼近、两者之间的数学误差推导，并深入剖析经验模型违反能量守恒与菲涅尔物理规律的根本缺陷，为后续全面迈入基于物理的渲染（PBR）奠定坚实的对比基石。

17.1 经验光照模型的历史演进与经典三要素分解
------------------------------------------------------------------------

在通用 GPU 出现之前，图形学先驱们将物体表面的光照效果解构为三个互不相干的经验分量之和：

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                  经典经验光照模型的三要素正交分解架构                   |
   +-------------------------------------------------------------------------+

   [ 最终表面出射光强 I_total ]
        =
   [ 1. 环境光分量 (Ambient Component - I_a) ]  ---> 模拟场景中无数次漫反射间接光照的经验常数底噪
        +
   [ 2. 漫反射分量 (Diffuse Component - I_d) ]  ---> 模拟粗糙表面向各个方向均匀散射的直接光能量
        +
   [ 3. 镜面高光分量 (Specular Component - I_s) ] -> 模拟光滑表面沿反射方向聚拢的明亮高光光斑

三要素经典组合方程形式为：

.. math::

   I_{	ext{total}} = k_a I_{	ext{ambient}} + \sum_{k} \left[ k_d I_{L,k} (\mathbf{n} \cdot \mathbf{l}_k) + k_s I_{L,k} (	ext{SpecularTerm}_k) \right]

其中 $k_a, k_d, k_s \in [0, 1]$ 分别为材质的环境光、漫反射与高光反射系数，$I_L$ 为光源发射强度。

顶点着色 Gouraud Shading vs 像素着色 Phong Shading
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在光栅化硬件的演进过程中，光照计算的执行阶段直接决定了画质表现：

.. list-table:: 顶点着色 Gouraud Shading 与像素着色 Phong Shading 微架构对比
   :widths: 20 35 45
   :header-rows: 1
   :class: tight-table

   * - 渲染技术
     - 计算发生阶段与数据流
     - 画面缺陷与微架构开销
   * - **Gouraud Shading (顶点光照)**
     - 顶点着色器计算各顶点处的 $I_{	ext{total}}$ 颜色，光栅化阶段在三角形内部进行**颜色双线性插值**
     - **马赫带效应（Mach Banding）**严重；无法呈现跨越三角形内部的局部高光光斑（若高光点在三角形中心则完全丢失）
   * - **Phong Shading (像素光照)**
     - 顶点着色器输出顶点法线，光栅化阶段对**法线向量进行重心坐标插值**，像素着色器逐像素归一化并执行完整光照计算
     - **平滑高光与精准边缘**；消除多边形棱角感；现代统一着色器架构的标准基石

17.2 Lambert 漫反射与 Half-Lambert 经验增强
------------------------------------------------------------------------

经典 Lambert 漫反射模型假定受光表面在微观上极度粗糙，入射光子在表面浅层经过数千次随机散射后，向半球所有出射方向等概率射出：

.. math::

   I_{	ext{diffuse}} = k_d I_L \max(\mathbf{n} \cdot \mathbf{l}, 0)

其中 $\mathbf{n}$ 为表面单位法线向量，$\mathbf{l}$ 为表面点指向光源的单位方向向量。

背光面全黑危机与截断伪影
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当表面法线背向光源（即 $\mathbf{n} \cdot \mathbf{l} \le 0$ 时），$\max$ 函数将漫反射项强行截断为 0。在缺乏高质量全局光照（GI）的经典光栅化管线中，这会导致物体背光面呈现死黑一片，完全丧失几何体感和拓扑轮廓。

Valve 半兰伯特 (Half-Lambert) 经验重映射模型
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

在开发《半条命 2》（Half-Life 2）期间，Valve 工程师针对角色面部与暗部细节丢失问题，提出了著名的 **Half-Lambert** 经验重映射公式：

.. math::

   f_{	ext{HalfLambert}} = \left( \alpha (\mathbf{n} \cdot \mathbf{l}) + \beta \right)^\gamma

在工业实践中，参数通常取 $\alpha = 0.5, \beta = 0.5, \gamma = 2.0$：

.. math::

   f_{	ext{HalfLambert}} = \left( 0.5 (\mathbf{n} \cdot \mathbf{l}) + 0.5 \right)^2

.. code-block:: text

   +-------------------------------------------------------------------------+
   |               Lambert vs Half-Lambert 光照响应曲线几何映射              |
   +-------------------------------------------------------------------------+

   Lambert 响应:       [-1.0 ---------------- 0.0 ++++++++++++++++++ 1.0] (n · l)
                                               |
                                               v max(n · l, 0)
                       [ 0.0 ---------------- 0.0 ++++++++++++++++++ 1.0] (背光面全为 0!)

   Half-Lambert 映射:  [-1.0 ---------------- 0.0 ++++++++++++++++++ 1.0] (n · l)
                                               |
                                               v 0.5 * (n · l) + 0.5  (将区间线性平移至 [0, 1])
                       [ 0.0 ---------------- 0.5 ------------------ 1.0]
                                               |
                                               v 平方 (^2) 保留高光梯度
                       [ 0.0 ---------------- 0.25 ----------------- 1.0] (背光面呈现柔和过渡!)

- **工程价值**：Half-Lambert 完全打破了辐射度量学的物理能量守恒，但它以极低的计算代价（单条 MAD 乘加指令加一次乘法），在视觉上提供了类似次表面散射（SSS）的柔和透光感，至今仍广泛应用于二次元赛璐璐（NPR）着色与移动端低成本光照中。

17.3 Phong 光照模型：反射向量与视线夹角
------------------------------------------------------------------------

1975 年，裴祥风（Bui Tuong Phong）在其博士论文中提出了计算机图形学史上第一个成功模拟光滑表面镜面高光的经验模型。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                        Phong 镜面反射几何系统                           |
   +-------------------------------------------------------------------------+

              入射光线反方向 l           法线 n           理想镜面反射方向 r
                      \                    |                    /
                       \                   |                   /
                        \                  |                  /  θ_r (夹角)
                         \                 |                 /  . 视线方向 v
                          \                |                / .
                           \       θ       |       θ       /.
                            \              |              /
       ----------------------\-------------+-------------/----------------------- (表面微元)
                              \            |            /
                               \           |           /

Phong 反射向量 $\mathbf{r}$ 的严格代数推导
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

设入射光线指向表面的方向为 $-\mathbf{l}$，表面单位法线为 $\mathbf{n}$。根据光学反射定律，入射角等于反射角，且入射光、法线与反射光共面：

1. 入射光在法线方向上的投影分量为 $(-\mathbf{l} \cdot \mathbf{n})\mathbf{n} = -(\mathbf{n} \cdot \mathbf{l})\mathbf{n}$；
2. 入射光垂直于法线的切向分量为 $-\mathbf{l} - [-(\mathbf{n} \cdot \mathbf{l})\mathbf{n}] = (\mathbf{n} \cdot \mathbf{l})\mathbf{n} - \mathbf{l}$；
3. 镜面反射方向 $\mathbf{r}$ 保持切向分量不变，法向分量反向：

.. math::

   \mathbf{r} = [(\mathbf{n} \cdot \mathbf{l})\mathbf{n} - \mathbf{l}] + (\mathbf{n} \cdot \mathbf{l})\mathbf{n} = 2(\mathbf{n} \cdot \mathbf{l})\mathbf{n} - \mathbf{l}

Phong 高光项的经验公式
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Phong 认为，真实物体的表面并非理想镜面，反射光不会完全局限在单一方向 $\mathbf{r}$，而是围绕 $\mathbf{r}$ 形成一个高光光斑（Specular Lobe）。视线方向 $\mathbf{v}$ 与反射方向 $\mathbf{r}$ 偏离越大，观测到的高光强度衰减越快：

.. math::

   I_{	ext{specular, Phong}} = k_s I_L \max(\mathbf{r} \cdot \mathbf{v}, 0)^s

- **光泽度指数（Shininess / Specular Power, $s$）**：
  $s$ 越大（如 $s=128 \sim 512$），$(\mathbf{r} \cdot \mathbf{v})^s$ 衰减越剧烈，高光光斑越小越锐利，表现为打磨抛光的金属或塑料；
  $s$ 越小（如 $s=2 \sim 16$），高光光斑越弥散，表现为粗糙磨砂材质。

Phong 模型的重大几何缺陷
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

当视线向量 $\mathbf{v}$ 与反射光向量 $\mathbf{r}$ 的夹角超过 $90^\circ$ 时（即 $\mathbf{r} \cdot \mathbf{v} \le 0$），高光值被强行截断为 0。在视线掠射观察时，即使视线位于表面上半球（$\mathbf{n} \cdot \mathbf{v} > 0$），也会在物体边缘产生极不自然的突变暗边。

17.4 Blinn-Phong 模型：半程向量与微表面几何逼近
------------------------------------------------------------------------

1977 年，Jim Blinn 针对 Phong 模型的计算复杂性与边缘截断问题，提出了革命性的改进模型——**Blinn-Phong 光照模型**。

.. code-block:: text

   +-------------------------------------------------------------------------+
   |                     Blinn-Phong 半程向量 (Halfway Vector)               |
   +-------------------------------------------------------------------------+

                 入射光线反方向 l        半程向量 h         视线方向 v
                         \                   |                   /
                          \                  |                  /
                           \                 |  θ_h            /
                            \                |  (夹角)        /
                             \               | .             /
                              \       θ      |.      θ      /
                               \             |             /
                                \            |            /
        -------------------------\-----------+-----------/----------------------- (表面微元)
                                  \       法线 n        /

半程向量 (Halfway Vector) 的定义与物理意义
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Blinn 引入了入射光方向 $\mathbf{l}$ 与视线方向 $\mathbf{v}$ 的角平分线单位向量——**半程向量（Halfway Vector, $\mathbf{h}$）**：

.. math::

   \mathbf{h} = \frac{\mathbf{l} + \mathbf{v}}{\|\mathbf{l} + \mathbf{v}\|}

- **微表面几何逼近本质**：若将宏观粗糙表面视为由无数微观各向同性微平面组成的集合，根据光学镜面反射定律，**只有那些微表面法线 $\mathbf{m}$ 恰好等于半程向量 $\mathbf{h}$ 的微平面，才能将来自光源 $\mathbf{l}$ 的光线精准反射进观察者的眼睛 $\mathbf{v}$**！
- 因此，宏观表面法线 $\mathbf{n}$ 与半程向量 $\mathbf{h}$ 的夹角余弦值 $\mathbf{n} \cdot \mathbf{h}$，物理上等价于微表面法线在 $\mathbf{h}$ 方向上的分布概率密度！

Blinn-Phong 高光计算方程
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. math::

   I_{	ext{specular, Blinn}} = k_s I_L \max(\mathbf{n} \cdot \mathbf{h}, 0)^{s'}

指数等价换算关系
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

由平面几何关系可知，当 $\mathbf{l}, \mathbf{n}, \mathbf{v}, \mathbf{r}$ 共面时，法线与半程向量的夹角 $	heta_h$ 约为主反射光与视线夹角 $	heta_r$ 的一半（$	heta_h \approx \frac{1}{2}	heta_r$）。根据泰勒级数展开：

.. math::

   \cos	heta_r \approx 1 - \frac{	heta_r^2}{2}, \quad \cos	heta_h \approx 1 - \frac{	heta_h^2}{2} = 1 - \frac{	heta_r^2}{8}

要使 Blinn-Phong 的高光衰减曲线与 Phong 达到相近的视觉光斑尺寸，高光指数需满足：

.. math::

   s' \approx 4s

17.5 Phong 与 Blinn-Phong 模型的数学误差推导与物理缺陷分析
------------------------------------------------------------------------

.. list-table:: Phong 模型与 Blinn-Phong 模型核心微架构与算法特性对比
   :widths: 20 40 40
   :header-rows: 1
   :class: tight-table

   * - 对比维度
     - 经典 Phong 模型
     - Blinn-Phong 模型
   * - **核心计算向量**
     - 视线与反射向量夹角 $\mathbf{r} \cdot \mathbf{v}$
     - **法线与半程向量夹角 $\mathbf{n} \cdot \mathbf{h}$**
   * - **GPU 指令开销**
     - 需计算 $\mathbf{r} = 2(\mathbf{n}\cdot\mathbf{l})\mathbf{n} - \mathbf{l}$（向量乘加 + 归一化）
     - **仅需一次加法 $\mathbf{l}+\mathbf{v}$ 与快速归一化 `rsqrt`**；方向光下全屏恒定
   * - **掠射角高光形态**
     - 大角度下高光光斑严重非自然变形拉伸，易产生硬黑边
     - **在掠射角下高光形态更趋圆润自然，消除截断伪影**
   * - **微表面理论契合度**
     - 纯经验几何拟合，无微观物理依据
     - **完美奠定了微表面法线分布函数（NDF）的理论雏形**

经典经验模型的四大根本性物理缺陷
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

尽管 Blinn-Phong 在实时图形学中统治了数十年，但在物理真实性层面存在致命缺陷：

1. **严重违反能量守恒定律 (Violation of Energy Conservation)**：
   在经典模型中，反射参数 $k_d$ 与 $k_s$ 由美术人员随意指定（例如 $k_d = 0.8, k_s = 0.8$，总反射能量达到 $160\%$），表面反射出的总光能远大于入射光能；此外，当高光指数 $s$ 增大时，光斑虽然收敛变小，但峰值强度并未相应提高，导致总能量凭空消失。
2. **完全缺失菲涅尔效应 (Lack of Fresnel Effect)**：
   自然界中任何非金属（如水、塑料、木材）在视线垂直射入时反射率仅为 $2\% \sim 5\%$，但在掠射角（$80^\circ \sim 90^\circ$）反射率均会逼近 $100\%$。经验模型中 $k_s$ 为各向同性常数，无法表现掠射边缘的高反光。
3. **无法表达微表面几何阴影与自遮蔽 (No Geometric Shadowing)**：
   经验模型未考虑微观微表面之间的相互遮挡（Masking and Shadowing），导致粗糙表面在侧向观察时光照过度明亮。
4. **金属与绝缘体（Dielectric vs Conductor）无差别处理**：
   无法表达金属内部自由电子对特定波长光子的选择性吸收（金属高光带颜色且无漫反射），以及绝缘体高光呈白色且具有强烈漫反射的物理区分。

改进版能量归一化 Blinn-Phong BRDF (Modified Blinn-Phong)
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

为了使 Blinn-Phong 能够嵌入渲染方程并满足能量守恒约束，图形学家推导出了带有**能量归一化系数（Normalization Factor）**的 Modified Blinn-Phong BRDF：

.. math::

   f_r(\mathbf{l}, \mathbf{v}) = \frac{k_d}{\pi} + k_s \frac{s + 8}{8\pi} (\mathbf{n} \cdot \mathbf{h})^s

通过乘以归一化因子 $\frac{s+8}{8\pi}$，保证了高光项在半球积分下的总能量始终不超过 $k_s$，成功解决了高光指数变化时的能量守恒问题。

17.6 现代 GPU 工业级 HLSL 实现
------------------------------------------------------------------------

以下为在现代 DirectX 12 / Vulkan 环境中封装的通用经典光照解算着色器：

.. code-block:: hlsl

   // HLSL: 经典光照模型工业级像素着色实现
   struct SurfaceData {
       float3 BaseColor;
       float3 NormalWS;
       float3 ViewDirWS;
       float  SpecularPower; // Shininess (如 32 ~ 256)
       float3 SpecularColor; // 经验高光颜色
   };

   struct DirectionalLight {
       float3 DirectionWS; // 指向光源的反方向
       float3 Color;       // 光源辐射通量强度
   };

   // 1. Half-Lambert 漫反射解算
   float3 EvaluateHalfLambert(SurfaceData surface, DirectionalLight light) {
       float NdotL = dot(surface.NormalWS, light.DirectionWS);
       float halfLambert = pow(0.5f * NdotL + 0.5f, 2.0f);
       return surface.BaseColor * light.Color * halfLambert;
   }

   // 2. 能量归一化 Blinn-Phong 完整着色解算
   float3 EvaluateNormalizedBlinnPhong(SurfaceData surface, DirectionalLight light) {
       float3 N = surface.NormalWS;
       float3 L = light.DirectionWS;
       float3 V = surface.ViewDirWS;

       float NdotL = saturate(dot(N, L));
       if (NdotL <= 0.0f) return float3(0.0f, 0.0f, 0.0f);

       // 朗伯漫反射项 (严格除以 π)
       float3 diffuseTerm = (surface.BaseColor / 3.14159265f) * NdotL;

       // 半程向量计算
       float3 H = normalize(L + V);
       float NdotH = saturate(dot(N, H));

       // 能量归一化系数 (s + 8) / (8π)
       float normFactor = (surface.SpecularPower + 8.0f) / (8.0f * 3.14159265f);
       float specularFactor = normFactor * pow(NdotH, surface.SpecularPower);
       float3 specularTerm = surface.SpecularColor * specularFactor * NdotL;

       // 总出射辐射率
       return (diffuseTerm + specularTerm) * light.Color;
   }

小结与下章导读
------------------------------------------------------------------------

本章系统回顾了经典经验光照模型的技术演进，剖析了 Lambert 漫反射与 Half-Lambert 柔化映射机理，推导了 Phong 视线反射向量与 Blinn-Phong 半程向量的几何代数方程，分析了半程向量作为微表面法线分布逼近的物理本质，并深入论证了经验模型在能量守恒、菲涅尔效应与材质物理分类上的根本局限。

为了彻底解决经验模型的物理失真，图形学界在 2010 年代掀起了基于物理的渲染（PBR）革命。下一章我们将正式开启现代工业级渲染基石——**基于物理的渲染 (PBR) 微表面理论：Cook-Torrance 框架与微面法线分布函数 (NDF)**，系统推导微观微表面几何统计模型、Cook-Torrance 分母微架构推导，以及 GGX / Trowbridge-Reitz 分布函数的严格数学解算。
