Linux Kernel 学习路径
=====================

目标
----

让会基础 C 语法的程序员逐步建立内核行为模型、系统观察能力、源码阅读方法和独立排错能力。

知识范围来源
------------

本路径需要先定位 ``aiBook`` 中 Linux Kernel 对应的 Roadmap、Roadmap 配套规范和文章生成控制文件。

这些文件负责说明用户原本想获得哪些 Linux Kernel 知识。旧 ``aiBook/docs/LinuxK`` 只用于观察原内容如何被过度扩充、哪些前置台阶缺失，以及为什么读完仍然无法形成判断。

Roadmap 中的条目不会直接变成章节。盘点后需要根据零基础学习依赖进行合并、拆分、重排或延后，同时记录每个知识项最终在哪里得到覆盖。

暂定能力阶段
------------

以下四个阶段只是当前学习设计假设，Roadmap 盘点后才能确认：

#. 建立内核行为模型；
#. 学会观察正在运行的内核；
#. 从现象进入固定源码；
#. 验证、排错与迁移。

旧的 17 章源码计划已经退出活动使用。它从函数顺序出发，不能代表零基础读者的学习顺序。
