Linux Kernel
============

这本书讲 Linux 内核。开头从设备上电后的真实执行过程进入，先交代内核取得控制权之前发生的必要故事。

当前正文
--------

#. `按下电源键后，CPU 从哪里取得第一条指令？ <01-power-on-first-instruction.rst>`_

当前主线
--------

::

   x86-64
   → QEMU q35
   → SeaBIOS
   → GRUB i386-pc
   → bzImage
   → Linux 6.12.95

当前只处理第一章。它从平台建立供电、时钟并释放处理器复位开始，追踪 CPU 的复位取指位置和
SeaBIOS 的 ``reset_vector``，结束在远跳转进入 ``entry_post``。

章节组织
--------

正文沿时间线连续讲述。故事达到适合一次阅读的篇幅，并遇到执行者、CPU 模式、运行环境或控制入口的
自然交接点时换章。每章末尾记录当前执行者、当前状态和下一入口；下一章从该位置直接继续。

章节不会按 Roadmap 条目机械切分，也不会在开头列出整本书的固定目录。
