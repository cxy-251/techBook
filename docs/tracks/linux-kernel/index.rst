Linux Kernel 学习路径
=====================

目标
----

让会基础 C 语法的程序员逐步建立内核行为模型、系统观察能力、源码阅读方法和独立排错能力。

当前阶段
--------

``design-pending``：尚未生成正式 unit。原先固定的 17 章源码目录已经退出活动使用。

固定阶段
--------

#. 建立内核行为模型；
#. 学会观察正在运行的内核；
#. 从现象进入固定源码；
#. 验证、排错与迁移。

下一步
------

先为第一阶段设计三到五个 unit。开场内容需要回答零基础读者为什么需要内核、用户态与内核态
如何通过真实现象区分，以及如何观察进程、文件和内存状态。不会直接从 ``primary_entry`` 或
``start_kernel`` 开始堆叠源码符号。
