学习单元标题
============

为什么现在需要它
----------------

给出一个真实场景或读者会遇到的困惑。用具体代码、输出、界面现象或错误信息说明问题。

先预测
------

在解释之前要求读者写下判断，并说明自己依据了什么。

最小示例
--------

.. literalinclude:: ../labs/<track>/<unit>/src/main.py
   :language: python
   :linenos:

真实结果
--------

.. code-block:: console

   $ <exact command>
   <real output>

逐步推理
--------

按照执行顺序解释具体代码、对象、状态变化和结果。每段只增加一个新判断。

改变一个条件
------------

修改一个参数、数据、调用方式或运行环境。先要求读者重新预测，再展示结果。

常见误解
--------

``错误模型``
   写出读者容易形成的判断。

``为什么错``
   指出它与哪项代码或证据冲突。

``正确模型``
   用能够迁移到其他场景的方式重述。

能力检查
--------

#. 问题必须来自前面的预测、示例或变化。
#. 问题应检查解释能力，而不是只检查术语记忆。

答案与推理
----------

每个答案说明：结论、推理步骤、证据位置，以及常见错误答案为什么不成立。

独立任务
--------

给出一个不能直接复制原示例完成的小型变化任务。

完成标准
--------

说明读者需要独立完成哪些动作，才能把本单元标记为已经学会。
