学习单元标题
============

为什么现在需要它
----------------

给出一个真实场景或读者会遇到的困惑。用具体代码、输出、界面现象、错误信息或源码行为说明问题。

先预测
------

在解释之前要求读者写下判断，并说明自己的依据。

最小示例
--------

.. code-block:: python

   # 直接在当前 RST 中放置最小示例。
   # 语言按实际主题调整。

真实结果
--------

.. code-block:: console

   $ <command when needed>
   <real output or observed result>

逐步推理
--------

按照执行顺序解释具体代码、对象、状态变化和结果。每段只增加一个新判断。

改变一个条件
------------

修改一个参数、数据、调用方式或运行环境。先要求读者重新预测，再展示变化后的结果。

常见误解
--------

``错误模型``
   写出读者容易形成的判断。

``为什么错``
   指出它与哪项代码、输出或现象冲突。

``正确模型``
   用能够迁移到其他场景的方式重述。

能力检查
--------

#. 问题必须来自前面的预测、示例或变化。
#. 问题应检查解释能力，而不是只检查术语记忆。

答案与推理
----------

每个答案说明结论、推理步骤、证据位置，以及常见错误答案为什么不成立。

独立任务
--------

给出一个不能直接复制原示例完成的小型变化任务。

完成标准
--------

说明读者需要独立完成哪些动作，才能把本单元标记为已经学会。

使用说明
--------

本文件是参考结构，不是必须逐标题填满的模板。可以合并或改名小节，但必须保留预测、证据、推理、
条件变化和迁移这条学习主链。代码、命令、输出和源码信息直接写在当前 RST 中。
