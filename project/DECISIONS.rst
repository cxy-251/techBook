长期决策
========

本文件保存跨对话必须继续遵守的长期决定。新 Agent 不得仅凭聊天记忆推翻这些决定。

D-001：私有学习内容仓库
-----------------------

状态：accepted

``cxy-251/techBook`` 是私有学习内容仓库，用于把 ``aiBook/docs`` 的技术方向重做为适合零基础
程序员逐步掌握的 RST 学习资料。

D-002：只使用 main
------------------

状态：accepted

当前所有工作直接提交到 ``main``。不创建功能分支和 PR，除非用户明确改变规则。

D-003：RST 直接阅读
-----------------

状态：accepted

项目说明、教学规则、学习路径和正式内容使用 reStructuredText。RST 源文件就是最终阅读内容，不依赖
Sphinx、HTML 或其他构建产物。

D-004：不建立构建与自动化系统
-----------------------------

状态：accepted

仓库不保留 Python 校验脚本、``pyproject.toml``、Sphinx 配置、GitHub Actions、CI、构建任务、
release 导出脚本或 Pages 发布配置。真实需要出现前不提前预留这些功能。

D-005：AGENTS 是接续入口
-----------------------

状态：accepted

任何新对话和新 Agent 都从根目录 ``AGENTS.md`` 恢复上下文。聊天记录不属于项目依赖。

D-006：不使用独立 Skill
----------------------

状态：accepted

仓库规则、内容设计和接续信息由 ``AGENTS.md``、``project/``、RST 与少量 TOML 状态文件共同提供。
不维护与这些文件重复的 Skill。

D-007：内容与证据写在同一 RST
-----------------------------

状态：accepted

代码、命令、输出、错误信息、源码片段和推理直接写入对应学习单元。源码级内容在当前 RST 中记录
repository、release、commit、平台和工具链，不使用全局 source lock 或独立 lab 层。

D-008：当前不批量生成
--------------------

状态：accepted

黄金学习单元经过实际阅读校准前，不批量迁移 ``aiBook/docs``，也不自动连续生成内容。

D-009：学习发生优先于内容覆盖
-----------------------------

状态：accepted

一个学习单元必须让读者经历预测、证据、推理、条件变化、误解修正和迁移任务。读完页面或看懂句子
不能单独视为学会。

D-010：按阶段小批次规划
----------------------

状态：accepted

路径开始时固定目标、能力层级、阶段与范围。每个阶段开始前设计一个有限批次，通常三到五个学习单元。
批次完成后根据真实阅读反馈设计下一批，不在开头冻结整条路径的全部章节。

D-011：问题必须有来源
--------------------

状态：accepted

每道能力检查题必须能够说明为什么要问、答案来自哪段代码或哪项现象、推理经过哪些步骤，以及常见
错误答案依赖了什么错误模型。

D-012：Narrative 不进入本仓库
-----------------------------

状态：accepted

文学、电影、电视剧和游戏编年史等 Narrative 内容继续留在旧仓库，不进入 ``techBook``。
