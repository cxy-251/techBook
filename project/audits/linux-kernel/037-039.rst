整批成功路径
------------

``第037章``
   ``decompress_kernel(O,V) → current heap retained → build-selected __decompress writes O with
   stage2 #PF demand maps → parse_elf copies phdrs then memmoves PT_LOAD.p_filesz → entry-L →
   conditional handle_relocations locates targets through O and adds V-L → cleanup compressed GHCB/IDT →
   return O+entry → RSI=Z and jump formal startup_64 → R15=Z, initial stack, GSBASE=0 → startup GDT/
   bringup IDT, lret CS → conditional SME → verify_cpu return ignored → derive p2v → __startup_64 records
   phys_base=O, fixes high tables, builds non-global identity map → CR3 early_top_pgt → high virtual jump
   common_startup_64``。

``第038章``
   ``common_startup_64 masks CR4 to PAE/LA57/conditional MCE → set PSE then PGE → SMP build reads
   smpboot_control=0 and __per_cpu_offset[0], non-SMP uses0 → current_task[0]=init_task → task stack →
   BSP trampoline_lock NULL → CPU0 gdt_page → zero selectors → GSBASE=CPU0 offset → early_setup_idt only
   reloads bringup/conditional VC → CPUID NX → EFER.SCE and conditional NXE/early PMD NX → CR0_STATE →

   ``runtime begins cr4_init_shadow → reset early root first511 and CR3 → conditional L5 layout → clear

关键地址、页表与IDT边界
----------------------

* decoder首次写未映射高地址O由compressed stage2 ``#PF`` 按2 MiB补图；
* relocatable ELF destination为 ``O+(p_paddr-L)``，formal BSS不由 ``p_memsz`` 在parse阶段清零；
* relocation target pointer由物理O构造，写入内容的x86-64 delta为 ``V-L``；
* fixed relocation tail只有32-bit与64-bit两组，旧稿inverse 32-bit第三组不存在；
* compressed cleanup把IDTR置空，formal startup另建bringup IDT；
* formal startup先令GSBASE=0；common取得logical CPU0后才写正式initial per-CPU offset；
* startup bringup IDT与common ``early_setup_idt`` 只按AMD-encryption build处理 ``#VC``；
* general ``early_idt_handler_array`` 要到039在SME/KASAN准备后才安装；
* formal ``__startup_64`` 的 ``phys_base/load_delta=O``，不是O-L；它被加到静态table的
  ``symbol-__START_KERNEL_map`` 编码上；
* transition identity PMD明确无global；high PMDs只保留实际 ``[_text,_end]`` 范围；
* ``reset_early_page_tables`` 清active root前511项后，Z不能再当identity pointer，copy使用
  ``__va(Z)`` 并由formal early ``#PF`` 建direct-map PMD；
* compressed ``#PF/kernel_add_identity_map`` 与formal
  ``#PF/early_make_pgtable`` 使用不同IDT、root、allocator与address semantics。

build/runtime条件
-----------------

* decoder与boot heap依 ``CONFIG_KERNEL_*``；当前只固定统一接口；
* ``CONFIG_X86_NEED_RELOCS`` 关闭时handle no-op；开启时V=L也直接返回；
* formal startup再次调用 ``verify_cpu``，但fixed汇编不测试EAX；failure halt只在034 compressed
  path；
* 4/5-level由此前CR4.LA57继承，formal helper只发布变量，不重新CPUID选择；
* SMP build走 ``smpboot_control=0``，!SMP直接RDX=0；当前结果均为boot CPU0；
* NX依runtime CPUID；AMD encryption、KASAN、TDX依build/runtime；
* ``load_ucode_bsp`` 可能为空inline，也可能因hypervisor/vendor/family/disable条件提前返回；
  helper调用不证明microcode revision更新。

发现并修复
----------

#. 三章全部改为固定7.2-rc1并补齐章末四节。
#. 删除旧稿不存在的inverse 32-bit relocation组，固定两组倒序扫描格式。
#. 区分O用于location/self-map与V用于64-bit relocation content delta。
#. 补齐高O首次写的compressed stage2 page-fault路径。
#. 修正 ``PT_LOAD`` 只搬 ``p_filesz``，formal BSS到039统一清零。
#. 修正formal startup ``GSBASE=0``，删除提前出现的fixed percpu data。
#. 按新fixed source改用 ``boot/startup/gdt_idt.c`` 与 ``map_kernel.c``，不再沿旧head64实现想象。
#. 修正formal ``verify_cpu`` 返回值未测试、 ``phys_base=O`` 与p2v推导。
#. 把bringup IDT/条件VC与039 general early IDT/page-fault helper分开。
#. 收紧038 CR4/PGE结论：当前identity PMD无global且PGE此前已清，不能宣称本次必然清掉旧项。
#. 固定CPU0 current_task、task stack、per-CPU GDT/GSBASE与noreturn initial_code边界。
#. 固定reset root、L5 layout、BSS/brk、SME/KASAN/global flush/IDT的不可交换顺序。
#. 修复command line遗漏，复制后有效字符串包含
   ``BOOT_IMAGE=/boot/bzImage root=/dev/sda1 ro console=ttyS0``。
#. 把“BSP microcode已更新”修为有条件helper attempt。

失败与未发生
------------

* decoder/ELF magic/alignment/relocation越界调用 ``error`` 永久halt；
* ``__startup_64`` 发现物理地址过宽或O未按2 MiB对齐时永久循环；
* formal startup与common期间general early ``#PF`` 尚不可用，必须等039 IDT安装；
* ``initial_code`` 正常不返回；返回即 ``ud2``；
* 本批没有AP、scheduler、maskable interrupt或用户态；
* initramfs仍只由copied global boot_params记录R/N，尚未unpack；
* ``x86_64_start_reservations``、platform quirks与generic ``start_kernel`` 未执行。
