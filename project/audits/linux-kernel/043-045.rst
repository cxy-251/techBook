页表、memblock与地址身份边界
----------------------------

* pgt buffer必须在 ``reserve_brk`` 前从 ``extend_brk`` 取得；之后 ``_brk_start=0``，通用
  ``alloc_low_pages`` 源码里的brk fallback不再是本次mapping的可靠第三后备；
* ``cleanup_highmap`` 清共享lower-level PMDs，但明确global translation回收在后面的CR3 load/TLB
  flush；
* E820 RAM、 ``memblock.memory``、 ``memblock.reserved`` 与direct-map PTE presence继续分开；
* low 1 MiB既reserved又mapped，reserved-in-RAM的kernel/initramfs也仍可mapped；
* direct map遍历memblock RAM ranges，不把全部 ``[0,max_pfn)`` holes当ordinary WB RAM；ISA range是
  明确的兼容例外；
* ``max_pfn/max_low_pfn/max_pfn_mapped/max_low_pfn_mapped`` 分别保留边界语义；
* active CR3直到 ``load_cr3(swapper_pg_dir)`` 才从 ``early_top_pgt`` 切为 ``init_top_pgt``；
* memblock current limit只扩到actual ``get_max_mapped()``，不直接扩到physical maximum。

printk、initramfs与ACPI table边界
-------------------------------

* ``setup_log_buf(1)`` 不设置per-CPU data ready； ``new_log_buf_len==0`` 是合法static-ring路径；
* dynamic printk需要text、descriptors、infos三块，partial allocation failure按逆序回滚；
* local IRQ关闭不能排除NMI，所以 ``prb`` 切换后还要补扫旧static ring；
* 第041章的early initrd reservation只防覆盖；本批才按actual ``pfn_mapped[]`` 建立可持续virtual
  identity或搬迁；
* fast path不复制，slow path先成功分配/复制，再free旧 ``[R,PAGE_ALIGN(R+N))``；
* ``initrd_end`` 使用真实N，physical reserved/check边界使用page-aligned E；
* ACPI table upgrade只early扫描专用cpio目录，不展开普通rootfs；
* ``acpi_boot_table_init`` 定位/reserve initial tables，不执行AML、namespace、MADT processor/
  IOAPIC或SRAT affinity解析。

early APIC与NUMA边界
-------------------

* fixed ``early_platform_quirks`` 只检测Apple DMI vendor，删除旧稿附加的PCI/HPET/IOMMU工作；
* ``early_acpi_process_madt`` 只处理MADT header LAPIC address与可选address override；
* fixed QEMU MADT没有Local APIC Address Override entry，helper返回0后设置
  ``acpi_lapic/smp_found_config``；这里没有处理Local APIC/x2APIC processor records；
* early MP parser在ACPI LAPIC有效时返回；fallback ``smp_read_mpc(...,early=true)`` 也只验证并注册
  LAPIC address，不遍历processor/IOAPIC/interrupt blocks；
* current ``setup_data=0`` 令 ``initial_dtb=0``，DT入口没有CPU/APIC tree可解析；
* SRAT可以先保存APIC-ID-to-node affinity与memory-node ranges，但不等于MADT possible CPU topology；
* ``memblock_set_node`` 改现有memory/reserved ranges的nid，不把holes变成RAM，也不启动buddy；
* ``numa_init_array`` 是缺失CPU-to-node mapping的round-robin兜底，不证明CPU已发现或online。

发现并修复
----------

#. 三章从历史6.12.95叙事整章重写为fixed Linux 7.2-rc1，并统一章末四节与fixed links。
#. 固定043新插入的CoCo RNG、EFI mirror/ESRT/MOK/boot-services、MPC和KHO scratch调用顺序。
#. 修正 ``reserve_brk`` 后allocator叙事： ``extend_brk`` 已因sentinel封存，不能作为current normal
   fallback。
#. 区分high-map PMD cleanup与后续CR3/TLB flush，不制造不存在的立即global flush。
#. 固定E820 type导入memblock的真实规则，并区分reserved-over-RAM与PTE mapping。
#. 修正real-mode reserve：size非0时即使allocation失败也reserve low 1MiB并清KHO scratch；当前仅
   reserve storage，尚未复制trampoline或发送INIT/SIPI。
#. 固定direct-map范围为ISA加memblock RAM，补充top-down/bottom-up自举、mapped PFN记录与active
   CR3切换边界。
#. 修正044旧initramfs文件名为固定 ``/boot/initramfs.img``，删除旧6.12.95 artifact。
#. 把initrd fast/relocate路径改成actual ``pfn_mapped[]`` 条件，未从未知RAM/builtin command line
   武断选择fast path。
#. 补齐printk三块allocation、失败回滚、record metadata migration和NMI-late补扫。
#. 区分ACPI override cpio scan、initial table reservation与后续full ACPI parsing。
#. 修正045最大错误：early MADT不枚举CPU条目，early MP也不建立processor topology。
#. 把 ``early_platform_quirks`` 收紧为fixed source实际Apple布尔判断。
#. 固定无DTB条件与NUMA source顺序，区分SRAT affinity、CPU topology、node online和buddy可分配。
#. 记录相邻046旧开头仍继承“045已建CPU topology”的历史错误，留在046—048原子批次修复，不把
   pending正文误标verified。

失败与未发生
------------

* pgt buffer/mapped allocation不能满足page-table自举会导致启动失败；本批不假定一个具体RAM数值；
* CoCo RNG不足会panic，initrd relocation分配或copy失败也会panic；fixed ordinary q35不选择CoCo；
* printk动态allocation失败安全保留旧static ring，不形成半发布状态；
* ACPI可被config/effective option/blacklist禁用，initial table locate失败会 ``disable_acpi``；
* 本批没有full MADT/MP/DT CPU enumeration、IOAPIC/IRQ routing、AP bring-up、zones或buddy init；
* initramfs未普通unpack，console未正式注册，IF未打开，没有schedule或用户态；
* 第046章正文仍pending，没有因相邻入口阅读而提升验证状态。
