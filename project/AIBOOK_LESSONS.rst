从 aiBook 得到的经验
===================

``aiBook`` 保存了大量技术方向、主题索引和部分有价值的链接，也暴露了一套不能继续复制的内容生产
方式。迁移任何旧内容前必须先阅读本文件。

失败一：承诺与实际能力不一致
----------------------------

旧章节开头经常承诺“深入理解”“掌握完整机制”“建立工程认知”，正文结束后读者只能复述几个术语，
无法预测代码、解释结果或独立完成任务。

``techBook`` 的学习结果必须描述一个可以检查的动作，例如：

* 能预测 ``list.append`` 的返回值；
* 能解释文件描述符如何关联到打开文件；
* 能根据编译错误定位模板推导失败的位置。

失败二：把覆盖完整当成教学完整
------------------------------

旧内容倾向于同时介绍定义、分类、历史、架构、实现、边界和工程实践。每项都出现一点，读者得到的是
名词地图，没有形成一条可以使用的思考路径。

新单元只引入解决当前困惑所需的内容。一个主题很大时，应拆成多次能力变化，不能用一篇长文制造
“已经覆盖”的错觉。

失败三：问题在正文完成后才被附加
------------------------------

旧章节的结尾问题经常缺少动机。读者不知道为什么需要回答，也不知道答案从哪段代码或哪个现象推出来。

新问题必须从开头预测、最小示例和真实结果自然产生。答案必须包含推理过程、证据位置和错误答案所依赖
的错误模型。

失败四：总结很多，关键推理很少
------------------------------

开头总结、段落总结和结尾总结会重复同一结论，却没有展示结论形成的过程。读者可能觉得句子都看懂了，
合上页面后仍然无法解释原因。

新内容优先展示输入、调用、对象、状态变化、输出和验证。重复结论必须删除。

失败五：代码只是文章插图
------------------------

旧代码常被嵌在正文中，用来证明文章“有示例”。它没有预测、预期输出、失败变体和完成标准。

新示例必须承担教学作用。读者需要先预测，再观察，再修改。代码、命令和输出直接保存在当前 RST 中，
使问题、证据和解释处在同一个可阅读文件里。

失败六：源码内容没有固定真实实现
------------------------------

一些旧章节使用“常见实现”“通常会”“主流实现大致如此”描述源码机制。读者无法定位真实代码，也无法
判断不同实现之间的差异。

需要源码证明的单元必须在当前 RST 中固定 repository、release、commit、平台和工具链。基础单元不
强行进入源码，先建立可观察的行为模型。

失败七：统一模板压过内容差异
------------------------------

语言基础、Linux 内核、Web 架构和移动系统被要求使用相似的章节结构。模板越完整，Agent 越容易机械
填充段落。

``techBook`` 只固定学习主链：预测、证据、推理、变化、迁移。具体标题、证据类型和呈现结构由内容决定。

失败八：预先冻结大量章节
------------------------

大型 Roadmap 会使后续工作退化为填目录。即使实际学习反馈表明顺序错误、章节重复或某个问题没有独立
价值，Agent 仍倾向于继续生成。

新仓库在路径开始时固定能力目标和阶段顺序。每个阶段只规划一个小批次 unit，实际阅读后再规划下一批。

失败九：把文件完成当成学会
--------------------------

旧内容的完成标准通常是页面已经生成、结构已经齐全。它没有要求读者独立预测、修改或迁移。

新 unit 只有在完成标准可以验证学习行为时才能标记为 ``complete``。是否学会依靠真实阅读与任务表现，
不能由脚本或文件状态代替。

迁移规则
--------

从 ``aiBook/docs`` 迁移时按以下顺序处理：

#. 提取旧内容想解决的真实困惑；
#. 写出读者完成后必须能做的动作；
#. 删除与该动作无关的背景和分类；
#. 设计一个需要先预测的最小示例或现象；
#. 在同一 RST 中提供真实结果和逐步推理；
#. 增加变化、误解、答案推理和独立任务；
#. 让旧章节只作为资料来源，不作为新单元的文本底稿。

允许保留的资产
--------------

* 有价值的主题方向；
* 已经核实的官方链接；
* 可定位的源码路径；
* 确实有教学作用的代码；
* 能暴露典型误解的失败案例。

默认重写的资产
--------------

* 宏大开场；
* 重复总结；
* 百科式分类；
* 与正文脱节的检查题；
* 没有推理过程的答案；
* 没有版本和运行证据的源码描述。
